## 데이터 관찰
- 이미지는 사실상 그레이스케일(R=G=B), 크기가 4~5종(675×480 ~ 1440×1024)
- 마스크 4색: 0 갈색(밝은 기지, 57%), 1 파랑(중간 회색의 길쭉한 상, 25%), 2 초록(어두운 다각형 입자, 9%), 3 회색(가는 어두운 침상, 7%)
- 이미지마다 노출이 크게 달라서 초록 상이 어떤 사진에선 회색, 어떤 사진에선 검정으로 보임
- 시료 ID(A###)가 train/valid 사이에 7개 겹침 → valid 점수가 약간 낙관적일 수 있음
- A57(train), A71(valid)에는 초록 상이 없음 → 해당 클래스 IoU를 계산에서 제외하는 방식(기본)과 1로 처리하는 방식을 함께 보고

## 방법
- 원본 해상도에서 512 크롭으로 학습(크기 비례 샘플링), Affine(스케일 0.7–1.4, 임의 회전), D4, 밝기/대비/감마, 블러/노이즈 증강
- 손실: CE + Dice, AdamW, warmup + cosine, 8000 iter × 배치 8, bf16 AMP
- 추론: 전체 이미지(32의 배수로 reflect 패딩) + D4 8방향 TTA
- **valid로 체크포인트를 고르지 않음**: 마지막 체크포인트만 저장하고 valid는 보고용으로만 사용

## 사용법 (서버)
```
python train.py --out ~/komap/runs/NAME --arch unet --encoder tu-convnext_small --norm imagenet
python predict.py --split valid --runs RUN1 [RUN2 ...] --out OUTDIR    # 앙상블 + 점수
python predict.py --split test  --runs RUN1 [RUN2 ...] --out OUTDIR    # 컬러 마스크 PNG
```
최종 제출용 모델은 설정이 정해진 뒤 `--train_splits train,valid`로 다시 학습한다.

## 공개 가중치: `weights/effb4_unet_v77/`
- U-Net + EfficientNet-B4 (ImageNet 사전학습), train 70장으로만 학습, 8000 iter, seed 0
- **valid 20장 mIoU 77.02%** (이미지별 4클래스 평균 → 20장 평균, D4 TTA 포함 / 없는 클래스를 1로 치면 77.62%)
- 클래스별 IoU: 기지 92.96 / 길쭉한 상 72.11 / 다각형 입자 89.90 / 침상 54.98
- `last.pt`는 Git LFS로 저장됨 → 클론 후 `git lfs pull`
- 데이터셋은 저장소에 포함하지 않음. `--data`로 `train/ valid/ test/` 구조의 폴더를 지정

```
python predict.py --data PATH/TO/KoMaP --split test --runs weights/effb4_unet_v77 --out pred_test
```

## 다른 컴퓨터에서 시드 실험 돌리기

```bash
pip install -r requirements.txt          # torch는 CUDA 버전에 맞춰 따로 설치
DATA=/path/to/KoMaP ./run_seeds.sh       # tw4000, 시드 2 3 4 (각 약 75분)
```

- 데이터 구조: `$DATA/train/{images,masks}`, `valid/{images,masks}`, `test/images`
- 환경변수: `SEEDS`(기본 `2 3 4`), `CONFIG`(`tw4000`|`tw5000`|`fixed3x`), `OUT`, `PY`, `CROP`, `BS`, `ITERS`, `WAIT_GPU=1`(공용 GPU에서 대기)
- **VRAM 15GB 이상 필요**(crop 1536 · batch 2에서 12.7GB). 부족하면 `CROP=1024`로 낮출 수 있으나 그 결과는 기존 1536 실행과 비교 불가.
- **`BS=1`은 쓰지 말 것** — BatchNorm이 배치 1에서 학습·추론이 어긋나 6라운드에서 79 → 71로 무너졌다.
- 끝나면 `summarize.py`가 설정별 시드 평균·표준편차를 출력한다. 기존 결과와 함께 보려면:
  `python summarize.py --runs runs/*/`
