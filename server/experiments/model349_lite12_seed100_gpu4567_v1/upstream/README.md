# KoMaP Model349 lite12 base v1.0.0

2026-10-08 사용자 결정에 따라 **12개 체크포인트 FP16 저장판을 후속 경량화 실험의 base**로 지정한다. 기존 Model349 릴리스와 원본 가중치는 보존한다. 이는 실험 기준판 지정이며 독립 일반화 개선이나 반복 측정에 의한 속도 개선 인증을 뜻하지 않는다.

이 저장소에는 실제 검증에 사용한 추론 코드·고정 설정·체크포인트 해시·한국어 레시피·결과를 담았다. **가중치 12개와 원본 데이터는 포함하지 않는다.** 정확한 결과 재현에는 [checkpoint_manifest.json](checkpoint_manifest.json)의 파일이 별도로 필요하다. 무작위 초기화나 현재 서버의 다른 학습 출력으로 대체하면 기록된 모델이 아니다.

## 고정 구성

| 경로 | 체크포인트 수 | 구성 |
|---|---:|---|
| 326 B4 | 2 | fold 1·3, 각 fold 동등 평균 |
| 가로 4000 B4 329 | 4 | fold 1·2·3·4 |
| HRNet336 | 1 | patch 512, overlap 170, batch 2, input scale 2 |
| 원본 해상도 269 | 1 | patch 1024, stride 576, scale 1 |
| 밝기별 고해상도 기본 경로 | 4 | model109, restart51, restart59, restart61; 영상마다 한 후보 선택 |

14개판에서 326 fold 2·4를 제외했다. EMA는 이미 제거된 상태이고 기존 EMA 밝기 구간은 restart51로 처리한다. 결합 비율과 후처리는 14개판과 동일하다. 10개판의 Al₃Ni 계수 0.8은 적용하지 않는다. TENT는 이미지별 BN 적응 **5단계**, 원본·밝기 보정 입력 예측을 유지한다.

FP16은 저장 형식이다. 모델 로드 후 FP32로 계산하므로 체크포인트 용량 감소를 연산 FP16/VRAM 감소로 해석하지 않는다. 고해상도 경로만 D4 TTA를 사용하며 B4/269/HRNet TTA는 실제 코드에서 꺼져 있다. YAML의 일부 TTA 문자열은 과거 설명 필드로 실행 호출보다 우선하지 않는다.

## 확인된 결과

평가는 이미지마다 4개 클래스 IoU를 평균한 뒤 valid20 이미지를 동일 비중으로 평균한다. 해당 이미지에 없는 클래스 IoU는 0이다. 클래스 순서는 Al₃Ni, Primary Si, Al, Eutectic Si다.

| 구성 | valid20 image mIoU | 체크포인트 바이트 | valid20 실제 시간 |
|---|---:|---:|---:|
| 14개 FP16 / TENT5 / OpenCV2 | 80.0656365% | 765,130,532 | 409.98초, 단회 |
| **12개 base / TENT5 / OpenCV2** | **80.1255610%** | **683,320,900** | **364.28초, 단회** |
| 10개 탐색판 / 계수 0.8 | 80.1188236% | 601,511,268 | 345.08초, 단회 |

12개판은 14 FP16 대비 약 10.69% 작다(683.32 MB, 651.67 MiB). 평균 valid 변화는 +0.0599245%p, 최악 이미지 변화는 −0.0922867%p이고 11장 개선·9장 악화했다. 기존 사전 기준은 lite15 대비 평균 손실 ≤0.01%p, 최악 이미지 손실 ≤0.10%p였다. 같은 조건 lite15 대비 +0.0611367%p / 최악 −0.0930182%p로 통과했다. 원본 23개판 대비 모든 이미지 보존을 의미하지 않는다. 10개판은 최악 이미지 손실 기준 초과로 채택하지 않았다.

test10은 정답이 없다. 실제 원본 재추론 결과 기존 lite15와 **99.8863577% 마스크 일치**(9,074,964픽셀 중 10,313픽셀 차이), 시간 429.04초 단회다. test mIoU나 정확도를 주장하지 않는다. 공유 서버의 단회 시간으로 속도 개선을 확정하지 않는다.

- [results/](results/): valid 이미지·클래스별 공식 점수와 일반화 진단, test 출력 비교 원자료.

fold 1·3은 반복 사용한 valid에서 선택했다. 전체 specimen bootstrap 95% 변화 구간은 [−0.0090074, +0.1662496]%p이며 선택 편향을 교정하지 않은 조건부 진단이다. train70·valid20·test10 총 100장뿐이고 추가 독립 정답이 없어 **일반화 개선은 미확인**이다. 현재 학습 출력과 동결된 배포 가중치의 텐서도 달라 strict OOF 성능을 인증할 수 없다.

이 버전 이후 후보는 이 12개판과 같은 원본 입력·평가·환경으로 비교한다. 설정을 바꿀 때 별도 버전을 만들고 valid 탐색 결과와 독립 검증 결과를 구분해 기록한다.
