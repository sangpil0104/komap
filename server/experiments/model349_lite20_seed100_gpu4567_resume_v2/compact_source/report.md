# fusion805 추가 경량화 실험 — lite23 후보

상태: GPU0 원본 영상 E 재추론 및 최종 PNG 독립 채점 완료. valid20 성능 유지 기준 통과. 기존 모델은 보존하며, 독립 일반화 검증을 완료한 릴리스로 표현하지 않는다.

| 구성 | 체크포인트 | FP32 가중치 용량 | valid20 평균 IoU |
|---|---:|---:|---:|
| fusion805 원본 | 27 | 4,553,557,386 bytes | 80.5006890946% |
| lite25 | 25 | 3,935,687,166 bytes | 80.5158924815% |
| lite23 (최종 원본 영상 검증) | 23 | 3,317,816,946 bytes | 80.5172704720% |

lite23는 R14 유지, E의 B4 4fold 유지, HR seed1 fold2·4와 seed2 fold1·4 유지, F1 유지한다. 원본 대비 가중치27.137% 감소, lite25 대비15.699% 감소. checkpoint 용량이며 코드 ZIP 크기나 추론 속도가 아니다.

사전 기준은 평균 손실≤0.01%p 및 최악 영상 손실≤0.10%p이다. 원본27/lite25/캐시R 기준 모두 통과했다. lite25 대비 평균+0.00157567%p, 최악−0.05436560%p; 원본 대비 평균+0.01677906%p, 최악−0.06896656%p. 242설정 중23개 이하에서는 이 후보만 통과했고22개 이하에는 통과 후보가 없었다.

그러나 전체242설정 검색을 시편 제외 후 다시 선택한 조건부LOSO는80.4708487349%, lite25 대비−0.04504375%p로 평균 기준에 실패했다. 동일 valid20 반복 탐색과 부모 선택 편향이 남는다. 독립 데이터 일반화 성능 유지는 입증되지 않았으며 최종 채택하지 않는다.

seed1 원본4fold20영상 추론의 FP16 가족 평균은 기존 캐시와20/20 exact. seed2는 이전 원본4fold 검증 결과 재사용. GPUF 재생 기준27/25 exact. 선택된23개 CPU 재계산은20장 stage1/2 모두 GPU마스크와 exact. 별도 기존 PNG 채점기로80.5174681510% 확인. 전체242설정 IoU/gate/LOSO를 별도 순수Python으로 독립 재집계해 일치 확인. R 제거3종과 양시드 조합 결과/실패attempt 보존.

실제 경량 실행기로 GPU0에서 원본20영상 E를 재추론했다. 두 shard10장씩 exit0이며, 전체20장 FP32 E 확률은 캐시 조합 결과와 exact다. R14는 이전 검증된 원본 추론 결과를 입력/가중치 SHA 확인 후 재사용했다. 최종 F CPU 마스크20장 별도 공식 PNG 채점 결과는 **80.5172704720%**다. 원본27 대비+0.01658138%p/최악−0.06894300%p, lite25 대비+0.00137799%p/최악−0.05436560%p로 모두 사전 기준을 통과했다. 캐시23 대비−0.00019768%p의 차이는 전체7픽셀이며, 모두 재사용한 raw R14와 canonical R14의 차이가 그대로 전파된 것으로 확인했다. 결과와 기준을 별도 순수Python으로 독립 재집계해 일치했다.

첫 후처리는 stage1 부모에 refiner 파일이 없는 경로를 참조해 중단됐다. 원래 실패 receipt와 동결 소스는 보존했다. 별도 retry는 원본 refiner 학습 완료 파일을 SHA 대조해 사용했고 저장된20장 E 확률을 재사용했다. 추론을 반복하지 않았다. 입력·가중치·원래 실행 소스 해시 불변을 확인했다. fresh_validation_gpu0에는 최종 채점, 품질 기준, R 차이 감사 및 독립 재집계 증거가 있다. 모든 관련 작업은 종료됐다.

이 검증은 변경된 E 전체의 원본 영상 재추론과 이전 raw R 재사용을 결합한 검증이다. R까지 이번에 새로 추론한 전체 파이프라인이라고 주장하지 않는다. 전체 새 추론 시간이나 속도 개선은 측정하지 않았다. GT는 별도 채점기만 읽고 test는 사용하지 않았다. 조건부LOSO의 평균 손실과 반복 valid 선택 편향은 여전히 남으므로 새 시편 성능 유지는 입증되지 않았다.

## 실행

부모 `Model349_fusion805` 재현 코드와 selected_assets.json의 원본 가중치를 준비한다. R 가중치는 부모의 Model349_exh14 아래, E/F는 assets 아래 해당 상대경로에 놓는다. 선택하지 않은 HRfold는 필요 없다. metadata는 해시 검사 후 누락된 경우만 복원한다.

```sh
python infer_compact.py --parent-package /path/Model349_fusion805 --assets /path/assets --input /path/images --output /path/new_output --gpus 0
```

이 artifact는 가중치와 데이터를 제외한 탐색용 코드다. 기존 fusion805 또는 lite25 artifact를 덮어쓰지 않는다. infer_compact/infer_expert 구문 및 CLI 검사는 통과했지만 원본20장 E 재추론과 F 결합·독립채점은 완료했다.
