# Model397: fixed Model329 B4 × Model392 HRNet family blend

Status: pre-result protocol, frozen 2026-10-03 03:25 UTC. This is a separate analysis; it does not alter or pause the active Model392 runner, runtime lock, OOF gate, full-train recipe, or one-shot evaluator. No Model392 score has been read to choose this protocol.

## Question and scope

Does adding a fixed 50:50 B4/HRNet family blend improve Model392's exactly-once train-OOF image-wise mIoU over Model392's two-seed mean, while also improving on the B4 parent?

No model is trained for Model397. Run only after the Model392 runner has terminated cleanly and its own pre-registered OOF/valid sequence is complete. The analysis uses train OOF probabilities and train masks; the separate final blend evaluation, if authorized by the gate below, is one additional official-valid look. Test data and labels remain excluded.

## Frozen arms and class/metric convention

For each of 70 train images, require exactly one held-out prediction from Model329 and one from each Model392 seed, each generated by a model that excluded that image's specimen group:

- `B4`: Model329 fold-held-out softmax probabilities.
- `H`: `0.5 × Model392_seed1 + 0.5 × Model392_seed2`.
- `C`: `0.5 × B4 + 0.25 × Model392_seed1 + 0.25 × Model392_seed2`.

All probabilities must use channel order `[Al, Al3Ni, Primary Si, Eutectic Si]`. Average probabilities, then argmax. No route, tuned weights, class bias, threshold, TTA, or post-processing.

Official metric: per image, calculate IoU for each of the four classes, assign IoU 0 when its union is empty, average the four class IoUs, then average images. Use the fixed 70-image/59-specimen-group, four-fold split. Any incomplete coverage, duplicate ID, group leakage, class-order mismatch, invalid probabilities, or model manifest/recipe/hash mismatch makes the result `UNESTIMABLE`.

## Pre-result input lock

Before computing any Model397 mIoU, create and verify a new lock over this protocol and evaluator, the existing Model396 input lock and Model329 OOF archives, the Model392 runtime/sequence locks, all eight Model392 OOF manifests/probability archives/checkpoint receipts, all fixed train masks, and (only for the gated final stage) Model329/Model392 official-valid probability archives and 20 official-valid masks. Never overwrite an existing lock or result. If Model392 did not pass its own OOF gate or its required artifacts are incomplete, do not run the final valid stage.

No Model397 scoring or CPU-heavy audit is allowed while Model392 is training or evaluating. This restriction is based on a prior CPU OOF audit coinciding with a marked slowdown in Model392; causality was not established, so avoid repeating the risk.

## OOF uncertainty and gate

Calculate paired image deltas and 20,000 specimen-group bootstrap draws, stratified within the four fixed folds, seed 397. Use the same draws for all comparisons. Report overall image-mean mIoU, four per-class changes, fold changes, Step4 change, image count, group count, and the largest positive specimen-group summed contribution divided by net summed gain.

Proceed to the fixed blend valid scorer only if **all** conditions pass:

1. `C − H` mean delta is at least `+0.50 pp`, its paired group-bootstrap 95% CI lower bound is above 0, at least 3/4 folds are positive, and the worst fold is at least `−0.30 pp`.
2. `C − B4` mean delta is at least `+0.30 pp`, its paired group-bootstrap 95% CI lower bound is above 0, and at least 3/4 folds are positive.
3. Against `H`, every class and Step4 delta is at least `−0.50 pp`.
4. No single specimen group contributes more than 25% of the net summed `C − H` image-score gain; non-positive net gain fails.

If any condition fails, record `NO_GO` and do not read official-valid masks for Model397. Do not change weights, thresholds, metrics, folds, or gates after seeing results.

This preserves 50:50 family weighting; note that the B4 valid branch averages four fold models whereas each train-OOF image has one held-out B4 model. Any valid result is a descriptive score on a small, adaptively reused 20-image set, not independent proof of 80% generalization. The scorer may report the two fixed component-arm scores (B4 and Model392) alongside the fixed blend for context only; they do not change the registered blend or authorize a route/weight choice. The 80% objective remains, and test remains sealed.
