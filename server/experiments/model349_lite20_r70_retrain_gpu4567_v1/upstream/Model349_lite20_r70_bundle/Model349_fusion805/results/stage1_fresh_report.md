# 1단계 R + E 원본 영상 재추론 결과

원본 영상부터 R의 릴리스 14가중치 및 E의 B4 4-fold/HRNet 2-seed × 4-fold를 다시 계산했다. F와 확신도 제한은 사용하지 않았다. 원본 소스·가중치 SHA는 불변이며, archive SHA/안전 추출 및 PNG/GT 20장 80개 IoU 독립 채점을 통과했다.

- 새 1단계 valid20: **80.4744236018%**
- 같은 실행의 R: 80.2309863330%
- 같은 실행 R 대비: +0.2434372688%p
- 기존 canonical R 대비: +0.2431922820%p
- 저장 부모 출력 기반 후보 대비: -0.0001970153%p
- 최악 영상: A71_step2_sample1, -0.2300308849%p
- 기존 영상별 손실 기준 통과: False

test10은 새 R 대비 161,731 / 9,074,964 픽셀이 달라, 일치율 98.21783315%다. 기존 canonical exh14 대비 일치율은 98.21780009%다. 영상별 변화 및 클래스 면적 비율은 comparison.json에 기록했다. test에는 정답이 없어 mIoU 또는 성능 증감을 주장하지 않는다.

1단계 시편 제외 80.4088%는 69개 실행 × 30개 규칙 전체를 매번 다시 선택한 값이다. 후보와 R 자체의 과거 valid 기반 개발 선택 편향까지 제거하지는 못한다. F는 조건부 CV에서 1단계 대비 손해로 미채택이다. 기존 base는 유지하며, 81% 목표 달성 여부는 별도 전체 요구사항 검증이 필요하다.

이번 검증은 **기존 고정 가중치의 전체 추론 재현**이다. 처음부터 재학습하지 않았으며, 재학습 성능의 재현성은 미확인이다. 10개 시드 paired 비교 계획과 새 OOF90 설계의 평가는 별도로 진행해야 한다. **valid20 81% 목표는 미달성**이다.
