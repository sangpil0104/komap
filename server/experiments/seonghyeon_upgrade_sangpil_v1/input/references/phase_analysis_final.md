## 분석 범위

사용자가 업로드한 `/mnt/data/dataset.zip`을 직접 압축 해제하여 분석하였다. 대형 신경망의 학습 결과가 아니라 파일 검사, 정답 마스크 통계, 진단 분류기들의 검증 결과이다.

데이터 ZIP SHA-256: `ebbc9e5e7e758152f006b4e515abf5d61309d432b8ae028330bc86e0372fbc55`

- train: 입력 70장, 정답 70장.
- valid: 입력 20장, 정답 20장.
- test: 입력 10장, 정답 없음.
- 모든 입력은 RGBA 형식이며 R=G=B, alpha=255이다. 입력의 유효 정보는 단일 그레이스케일 채널이다.
- 모든 이미지와 대응 정답의 공간 해상도가 일치한다. 정답 RGB 값은 아래 네 색상으로만 구성된다.
- 완전히 동일한 픽셀 배열을 갖는 입력 중복은 100장 중 검출되지 않았다. 이동·회전·부분중첩 또는 유사 시야의 중복까지 검사한 것은 아니다.

## 진단 실험

### A. 밝기만 사용한 분류기

학습 이미지 70장 각각에서 클래스×그레이스케일(4×256) 빈도를 계산한다. 각 이미지의 픽셀 수로 정규화한 빈도를 합하고, 밝기값마다 가장 빈번한 클래스를 예측하는 lookup table을 만든다. 원본 밝기 이외의 공간 정보나 다른 메타데이터는 사용하지 않는다. 이 방법은 mIoU에 대해 최적화한 밝기 분류기가 아니며 밝기 기반 방법의 성능 상한을 뜻하지 않는다.

### B. 다중 스케일 국소 통계 기반 Extra Trees

학습 이미지 70장마다 균일 무작위로 3,000개 픽셀을 선택하여 총 210,000개 픽셀로 학습한다. 검증 마스크는 분류기 학습에 사용하지 않았다. 하이퍼파라미터 검색은 수행하지 않았다.

28개 특징: raw gray, 이미지별 z-score, sigma=1/2/4/8/16의 Gaussian 평균·표준편차·원본 대비 잔차, Sobel x/y의 절댓값, 이미지별 밝기 CDF, 이미지 전체 평균·표준편차·밝기 5/25/50/75/95 백분위수, 이미지 폭/1440.

ExtraTreesClassifier 설정: n_estimators=120, max_depth=24, min_samples_leaf=3, max_features=0.8, random_state=2026.

### 평가

두 분류기는 검증 20장의 모든 픽셀에서 평가했다. 각 이미지에서 클래스별 IoU를 계산하고, 4개 클래스 평균을 구한 후 20장의 평균을 사용했다. 코드에는 union=0을 제외하는 처리가 있으나 두 진단 분류기의 실제 검증 confusion matrix에는 union=0 클래스가 없어 이 처리가 점수에 영향을 주지 않는다.

| 클래스 또는 지표 | 밝기만 | 다중 스케일 국소 통계 + Extra Trees |
|---|---:|---:|
| 초정 Si (Primary Si) 평균 IoU | 47.7770% | 79.7433% |
| Al3Ni 평균 IoU | 48.9222% | 66.7762% |
| 공정 Si (Eutectic Si) 평균 IoU | 9.4767% | 49.9531% |
| Al 평균 IoU | 86.6970% | 92.4770% |
| 이미지별 평균 mIoU | 48.2182% | 72.2374% |

국소 통계 분류기의 개선은 국소 특징뿐 아니라 밝기 정규화 및 이미지 전체 통계 등 여러 변경을 함께 포함하므로, 각 구성 요소의 독립적인 기여를 측정한 ablation으로 해석해서는 안 된다.

파일명 접두사가 같다는 사실만으로 동일 시편, 동일 시야 또는 데이터 누수라고 확정할 수는 없다. 그룹 교차검증을 함께 점검할 근거로만 사용한다.

## 해석 범위

이 결과는 원해상도 세부 정보, 국소 텍스처, 이미지별 밝기 조건, 넓은 문맥을 함께 활용할 설계 근거이다. DINOv3/CNN 하이브리드, 정밀 보정 모듈, 앙상블은 이 진단 실험에서 학습하지 않았으므로 그 성능이나 기존 구조 대비 우월성을 수치로 검증한 것은 아니다. 테스트 정답은 없으므로 테스트 mIoU는 계산하지 않았다.

## 보충 실험: 국소 특징의 영향 비교

밝기 정규화와 이미지 전체 통계의 효과를 공간 문맥의 효과와 구분하기 위해, B 실험과 같은 210,000개 학습 픽셀 및 같은 Extra Trees 설정에서 국소 특징을 제거한 C 실험을 수행하였다. C는 11개 특징(raw gray, z-score, 밝기 CDF, 전체 평균/표준편차/5·25·50·75·95 백분위수, width/1440)을 사용한다. Gaussian 국소 평균·표준편차·잔차 및 Sobel 기울기는 사용하지 않는다.

| 지표 | A: 원본 밝기 lookup | C: 밝기·이미지 전체 통계, Extra Trees | B: 국소 특징 포함, Extra Trees |
|---|---:|---:|---:|
| 초정 Si 평균 IoU | 47.7770% | 57.6995% | 79.7433% |
| Al3Ni 평균 IoU | 48.9222% | 56.6766% | 66.7762% |
| 공정 Si 평균 IoU | 9.4767% | 26.6709% | 49.9531% |
| Al 평균 IoU | 86.6970% | 89.2964% | 92.4770% |
| 이미지별 평균 mIoU | 48.2182% | 57.5859% | 72.2374% |

B와 C의 mIoU 차이는 14.6516%p이다. 이 결과는 이 분류기 설정에서 국소 특징이 유효했다는 실험 근거이지, 특정 신경망 구조의 우월성 또는 mIoU 상한의 증명이 아니다.
