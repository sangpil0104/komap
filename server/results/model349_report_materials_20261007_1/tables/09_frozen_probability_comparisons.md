# 저장 확률 기반 후처리·결합 비교

2026-10-07에 기존 validation 확률 캐시만 사용해 추가 산출한 사후 분석이다. 새로운 학습, checkpoint 선택, 계수 탐색을 수행하지 않았다. 원래 Model349 조건이 기존 마스크20장과 모두 픽셀 단위로 일치함을 확인했다.

| 조건 | image mIoU (%) | 원래 대비 (%p) | Al3Ni | Primary Si | Al | Eutectic Si |
| --- | --- | --- | --- | --- | --- | --- |
| Model349 전체 | 80.068799 | +0.000000 | 76.839582 | 87.101137 | 94.363896 | 61.970580 |
| 모든 최종 보정 제거 | 78.848453 | -1.220346 | 73.681947 | 86.846897 | 94.243305 | 60.621664 |
| prior·bias만 유지 | 79.984505 | -0.084294 | 76.715748 | 86.996195 | 94.375681 | 61.850396 |
| Primary Si 정리 제거 | 80.008310 | -0.060489 | 76.848374 | 87.055743 | 94.365692 | 61.763431 |
| 공간 필터 제거 | 80.068934 | +0.000135 | 76.716090 | 87.097415 | 94.373864 | 62.088368 |
| 밝기 prior 제거 | 79.644082 | -0.424717 | 76.035946 | 87.206423 | 94.222761 | 61.111197 |
| 7개 확률원의 균등 평균 | 79.614510 | -0.454289 | 76.225920 | 86.902596 | 94.227995 | 61.101527 |

클래스 열의 단위는 %이며 이미지별 클래스 IoU의 평균이다.

| 조건 | 변경 정의 |
| --- | --- |
| Model349 전체 | 기존 클래스별 결합 + prior·bias + 공간 필터 + Primary Si 정리 |
| 모든 최종 보정 제거 | 동일한 클래스별 결합 확률의 argmax; prior·bias·공간 필터·정리 제거 |
| prior·bias만 유지 | 동일한 결합; prior·bias 유지, 공간 필터와 정리 제거 |
| Primary Si 정리 제거 | 동일한 결합·prior·bias·공간 필터 유지; 연결 성분·1% 규칙 제거 |
| 공간 필터 제거 | 동일한 결합·prior·bias·Primary Si 정리 유지; Gaussian·bilateral 제거 |
| 밝기 prior 제거 | prior_scale=0; 클래스 bias, 공간 필터, Primary Si 정리는 유지 |
| 7개 확률원의 균등 평균 | 기본 확률과 Model269/322/326/329/336/347을 각 1/7로 평균; 원래 후처리 유지 |

균등 평균에서 기본 확률은 이미 내부 앙상블이다. 따라서 이 조건은 모든 신경망 checkpoint에 동일 가중치를 준 결과가 아니라, 기본 확률 및 6개 전문가 확률원의 평균이다. B4 각 확률원에는 4-fold 평균이 들어 있다. 평균 조건에도 원래 후처리와 계수를 그대로 사용하여 최적화하지 않았다.

**해석**

모든 최종 보정을 제거하면 원래 Model349보다 1.220346%p 낮다. 밝기 prior를 제거하면 0.424717%p, 7개 확률원을 균등 평균하면 0.454289%p 낮다. 각 차이는 이 고정 설정과 검증20장의 관측 결과이다.

공간 필터만 제거한 점수는 80.068934%로 원래보다 +0.000135%p 높다. 이 자료에서는 공간 필터의 개선 효과를 주장하기 어렵다. 이 매우 작은 차이로 새로운 우수 모델을 확정하지 않으며, 기존 보고 점수80.068799%와 구분한다.

**재학습이 있어야 분리 가능한 비교**

| 비교 | 현재 상태 | 필요 조건 |
| --- | --- | --- |
| Raw만 입력 vs Raw/Z/CDF | 인과적 비교 미수행 | 같은 split·backbone·seed·예산으로 입력만 바꿔 학습 |
| ASPP 유무 | 인과적 비교 미수행 | 같은 학습 조건에서 모듈만 변경 |

위 미수행 항목의 점수는 만들어 넣지 않았다. 새 학습은 사용자가 시작한다.
