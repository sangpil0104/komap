# 그림 캡션 및 10페이지 배치안

제출 양식의 필수 소제목을 유지하고 아래 자료를 골라 배치한다. 모든 보조 그림을 본문에 넣기보다 결과를 설명하는 대표 자료를 선택한다.

| 페이지 | 내용 | 우선 자료 |
| --- | --- | --- |
| 1 | 팀 정보·배경·아이디어·파급효과 | 배경과 기대효과는 각5줄 이내; 팀 정보는 직접 기입 |
| 2–3 | 1-1 핵심 내용 / 1-2 배경 / 1-3 EDA | 그림01·03·04·05, 표01·02 |
| 4 | 2-1 전처리 방법 / 2-2 절차 | 그림07·08, 표03 |
| 5–6 | 3-1 알고리즘 / 3-2 모델링 방법 | 그림09·12, 표04·05·06; 상세도10·11은 공간에 따라 선택 |
| 7 | 3-3 성능: 점수와 비교 | 그림13·14, 표07·08 |
| 8 | 3-3 성능: 개별 결과 | 기존 보유 comparison과 그림15 또는16 |
| 9 | 3-3 성능: 추가 분석 | 그림17, 표09 |
| 10 | 한계·재현·test 산출물 안내 | 표10, 필요하면 그림06·18 |

| 08 | 2-2 전처리 절차 | [전처리·추론 흐름](../figures/08_preprocessing_flow.png) | B4와 HRNet 분기의 전처리 및 추론 차이. ResNet 기반 기본 분기는 별도 구조도와 설정표를 참조한다. |
| 09 | 3-2 모델링 방법 | [Model349 전체 구조](../figures/09_model349_pipeline.png) | 원본 체크포인트를 사용하는 여러 분기의 확률을 순차 결합한 후 영상 통계와 공간 보정을 적용한다. Model349 성능은 이 전체 파이프라인의 결과이다. |
| 10 | 3-1 알고리즘 / 3-2 모델링 | [ResNet34·ASPP·native stem](../figures/10_resnet_aspp_native.png) | 기본 ResNet 계열의 encoder/decoder와 Model269의 추가 native stem을 함께 표시했다. RGB 계열과 표현 변환 계열의 dilation 설정은 다르다. |
| 11 | 3-1 알고리즘 / 3-2 모델링 | [B4·HRNet 전문가 구조](../figures/11_b4_hrnet_architecture.png) | B4 계열과 HRNet 계열의 encoder, decoder, 출력 head 차이. Boundary head는 학습 보조용이다. |
| 12 | 3-2 모델링 방법 | [클래스별 결합 계수](../figures/12_classwise_fusion.png) | 선택된 전문가와 각 단계의 γ. 표에 보이는 γ는 해당 단계에서 사용한 혼합 계수이며 전체 시스템의 선형 가중치가 아니다. |
| 13 | 3-3 성능 | [단계별 성능](../figures/13_stage_performance.png) | Model339·341·346·349의 동일 실행 기록. 점수는 image mIoU(empty=0), 차이는 percentage point이다. |
| 14 | 3-3 성능 | [클래스별 IoU](../figures/14_class_iou.png) | Al3Ni, Primary Si, Al, Eutectic Si의 이미지별 IoU 평균. 점선은 네 클래스 평균과 같은 전체 image mIoU이다. |

이미지는300dpi PNG이다. 입력 표현 그림은 실제 입력 함수로 계산했고 구조도는 소스에 근거해 그렸다. 통계 그래프의 숫자는 동봉된 표와 대조할 수 있다. 기존 예측 마스크·comparison은 이 ZIP에 중복 수록하지 않았다.
