배경 및 아이디어 소개(요약)


아이디어 제안 배경 — 5문장 요약

알루미늄 합금 현미경 영상을 Al₃Ni, Primary Si, Al, Eutectic Si의 네 상으로
분할하는 것을 목표로 한다. 제공 학습 영상이 70장이므로 사전학습 특징, 패치
학습, 증강과 시편 단위 분할을 조합했다. 영상별 밝기·해상도 차이와 작은 상의
경계를 함께 다루기 위해 서로 다른 입력 표현과 신경망 계열을 활용했다. 기존
Model349의 고정 추론 패키지 R에 독립 전문가 E의 클래스 선택 규칙을
결합하고, OOF 예측으로 학습한 작은 잔차 보정기 F도 평가했다. 현재
재학습에서는 R+E가 80.236507%, R+E+F가 80.267268%의 valid20 image mIoU를
기록했다. [S02–S08]


파급효과 — 5문장 요약

네 상의 위치와 경계를 일관된 마스크로 제공하여 반복적인 영상 판독을 보조할
수 있다. 원본·예측·정답·오류를 함께 보여 주어 어떤 상과 영상에서 수정이
필요한지 검토할 수 있다. 영상별 지표와 원본 코드·가중치 해시를 연결해 실험
결과를 추적할 수 있다. 향후 독립 시편 평가와 추가 정답 검증이 확보되면 상
면적 분석 등의 후속 작업에 연결할 수 있다. 본 결과는 물성·탄성 측정의 대체
성능이나 현장 적용 효과를 검증한 것은 아니다.

본 문서는 원본 양식의 필수 목차를 유지한 확장본이다. 사용자 요청에 따라
원본 양식의 10페이지 제한은 적용하지 않았다. 그림·표와 검증 20장 전체
비교를 포함하며, 미확인 인적 사항과 현재 모델의 test10 제출물 상태를
명시한다.

① 분석(EDA) 개요


1-1. 분석 핵심 내용

분석 대상은 현미경 영상의 픽셀 단위 다중 클래스 분할이다. 각 픽셀을 네 상
중 하나에 배정하고, 원본 해상도의 마스크로 복원한다. 데이터
수·해상도·밝기·클래스 구성·시편 식별자를 함께 확인하여 모델 입력과 평가
방식의 근거를 마련했다. 파일 이름의 A번호는 시편 그룹을 나타내는 식별자로
사용하되, 제공 자료만으로 촬영 조건이나 물리적 배율을 추정하지 않았다.
[S02]

1-2. 분석 배경

단일 영상 안에서도 넓은 Al 영역과 상대적으로 작은 상이 함께 존재한다. 단순
픽셀 빈도 중심의 판단만으로는 작은 상의 오류를 충분히 설명하기 어렵다. 이
프로젝트의 평가식은 이미지와 클래스에 동일한 가중치를 주므로, 데이터의 픽셀
구성비와 목표 지표를 구분해야 한다. 작은 클래스의 오검출·미검출, 얇은
경계와 국소 조직의 혼동을 이미지별로 확인하는 것이 필요하다. [S01, S02]

현재 접근은 하나의 큰 모델로 모든 경우를 해결하기보다 입력 표현과 특징 추출
방식이 다른 모델을 조합한다. 다만 모델 종류가 많다는 사실만으로 개선이
입증되는 것은 아니다. 보고서에서는 실제 같은 실행의 R, E, stage1, stage2를
함께 비교하고, 평균뿐 아니라 개별 영상의 손실도 제시한다. [S07]

② 데이터 전처리


2-1. 전처리 방법

원본 이미지와 마스크의 크기 일치, 이미지·정답 이름 대응, 팔레트 값과 파일
해시를 검증했다. 학습 전에는 분할별 파일 수를 고정하고, unknown mask
color가 있으면 실행을 중단하도록 구성했다. 정답은 route ID 0–3으로 복원하며
원본 해상도의 좌표를 유지해 최종 채점한다. [S02, S03]

그림 7. Raw/Z-score/CDF 표현. 같은 원본에서 절대 밝기·상대 밝기·밝기 순위를
구성한다. CDF의 표시 예시와 실제 구현의 세부 변환은 구분한다. [S02, S05]

B4의 세 입력 채널은 grayscale g∈[0,1]에서 raw, 전체 영상의 평균·표준편차를
이용한 z-score, 해당 영상의 CDF로 구성한다. patch를 자른 뒤 통계를 다시
계산하는 방식과 구분한다. 다음 식은 B4 표현의 scaling을 설명하며, ResNet
표현 계열의 CDF 구현을 동일 함수로 대체하는 근거는 아니다. [S05]

  X = [(g−0.5)/0.25, clip((g−μ)/(σ+10⁻⁶), −4, 4)/3, (CDF(g)−0.5)/0.288675]

E HRNet은 각 fold의 학습 영상에서 결정한 modal target width를 checkpoint에
저장하고, 추론 시 원본 너비에 맞춘 effective input scale과 overlap을
계산한다. 현재 저장된 seed1/fold1의 target_width는 1230이다. 모든 fold 값을
임의로 하나로 덮어쓰지 않고 각 checkpoint의 전처리 metadata를 읽는다. [S05]

2-2. 전처리 절차

절차 1: 원본 train70/valid20과 test10 입력을 식별하고 해시·크기·색상을
확인한다. 절차 2: train70을 A번호 기준 4-fold로 나누고, 각 fold의 학습·held-
out 시편이 겹치지 않는지 확인한다. 절차 3: 각 모델에 맞는 입력 표현과 크기
정규화를 적용한 뒤 학습 patch를 추출한다. 절차 4: 학습된 모델의 예측을 원본
좌표로 복원하고 클래스 순서를 통일한다. 절차 5: family 확률의 반올림 순서를
유지하여 E를 결합하고, train70 OOF를 F의 입력으로 저장한다. 절차 6:
valid20의 최종 label을 PNG로 저장한 뒤 정답과 독립 채점한다. [S03–S07, S13]

                                    [pic]

그림 8. OOF 학습 절차. F의 각 학습 입력은 해당 이미지를 학습에서 제외한
전문가의 예측이다. valid20 정답은 F 학습에 사용하지 않는다. 공식
train/valid 시편 중복과는 별개의 통제다. [S03, S06]

E의 valid 예측은 각 family의 네 fold를 float32로 평균하고, family별 평균을
한 번 float16으로 반올림한 다음 다시 float32로 결합한다. 각 fold를 먼저
float16으로 바꾸어 평균하는 연산과 일반적으로 같지 않다. 반면 OOF에서는
해당 이미지를 제외한 한 fold의 모델만 각 family에서 사용한다. 이 수치
처리와 클래스 순서가 재현의 일부다. [S05]




③ 모델링


3-1. 배경/알고리즘 소개

U-Net은 encoder에서 얻은 문맥과 decoder의 위치 복원을 skip 연결로 결합한다.
U-Net++는 중첩된 skip 경로를 사용하여 여러 깊이의 특징을 연결한다. 이
프로젝트의 ResNet compact U-Net++ 구현과 SMP의 HRNet U-Net++는 서로 다른
구현이므로 같은 이름만으로 구조가 완전히 같다고 설명하지 않는다. [P01, P02,
S04, S05]

ResNet은 잔차 연결을 통해 특징을 학습하고, EfficientNet은 네트워크의
깊이·너비·입력 크기를 함께 고려한 계열이다. HRNet은 여러 해상도의 특징
경로를 유지하고 정보를 교환하는 구조다. 여기서는 이 서로 다른 특징 추출
계열을 분할 decoder와 연결했다. 원 논문의 벤치마크 성능을 본 합금 영상의
성능으로 이전해 주장하지 않는다. [P03, P04, P05]

ASPP는 서로 다른 dilation을 가진 convolution으로 여러 범위의 문맥을
처리한다. 프로젝트의 ResNet 분기에는 잔차 형태의 ASPP가 들어가며 일부
경로는 원본 해상도의 native stem을 추가한다. TENT는 정답 없이 예측
entropy를 줄이는 test-time adaptation 방법으로, R의 선택된 고해상도
경로에서 이미지마다 적용한다. 고정 checkpoint 학습과 추론 중 일시적 적응을
구분해야 한다. [P06, P07, S04]

                                    [pic]

그림 9. 신경망 계열 비교. 세 계열의 계산 흐름을 요약했다. F는 11,876
parameters이며 최종 convolution을 0으로 초기화한다. [S04–S06]

Model349 또는 fusion805라는 이름은 단일 신경망 층의 이름이 아니라 모델
집합, 입력 표현, 확률 결합, 라우팅, 후처리를 묶은 실험·패키지 식별자다.
fusion805의 파일명 역시 현재 새 가중치가 80.5%를 보장한다는 뜻이 아니다.
GitHub에서는 F를 제외한 stage1을 대표 후보로 두고 stage2를 탐색 기록으로
보존한다. [S08]

표 14. E의 시편 단위 4-fold

|fold                     |학습 이미지              |held-out 이미지          |

train70의 59개 시편 그룹을 고정 분할. 각 학습 영상은 정확히 한 held-out
fold에 들어간다. [S12, S13]

     P_E = 0.50 · Q(P_B4) + 0.25 · Q(P_HR,seed1) + 0.25 · Q(P_HR,seed2)

여기서 각 P̄는 family의 네 fold 평균이고 Q는 float16 반올림 후 float32
복원이다. OOF에서는 평균 대신 해당 held-out fold 모델의 확률을 사용한다. 팀
순서를 route 순서로 [1,2,0,3] 재배열하며, argmax 동률에서는 원래 팀 클래스
우선순위를 유지한다. [S05]


3-2-3. F: OOF 확률의 제한된 잔차 보정

F는 E의 예측을 입력으로 사용하는 3층 convolution 모델이다. 네 채널 log
probability와 한 채널 gray로부터 5채널 입력을 만든다. 구조는
Conv3×3(5→32)–SiLU–Conv3×3(32→32)–SiLU–Conv3×3(32→4)이며 총 11,876개
parameter다. 마지막 convolution을 0으로 초기화하므로 시작 시 출력은 부모
log probability와 같다. [S06]

 L = log(max(P_E, 10⁻⁷)), Δ = tanh(Fθ([clip(L−mean_c(L),−8,8)/4, 2g_z−1])),
                                  L′ = L+Δ

gray 입력 g_z는 원본 전체 영상의 z-score를 ±3으로 자르고 z/6+0.5로 [0,1]
범위에 맞춘다. 표준편차가 10⁻⁶보다 작으면 0.5를 사용한다. 학습에서는 이
변환 후 crop하고, 추론에서도 전체 이미지 통계를 사용한다. tanh에 의해 각
logit 잔차는 −1부터 1 사이로 제한된다. [S06]

               Loss_F = 0.5 CE + 0.5 Dice loss + 0.05 mean(Δ²)

학습 데이터는 새 E 모델의 train70 OOF 확률, 원본 gray, train70 정답이다.
이미지당 16개 sample, batch8로 epoch당 140 step을 수행하며 8 epochs의 총
1,120 update를 고정한다. seed81349, AdamW lr=10⁻³, weight decay=10⁻⁴,
cosine T_max=8, gradient clip=1을 사용했다. 클래스 0·3 중심 crop과 균등
crop을 섞으며, valid/test 정답은 F 학습에 넣지 않았다. [S06, S13]

                                    [pic]

그림 11. F 학습 곡선. 학습 기록의 평균 loss를 그대로 표시했다. 마지막
epoch8을 고정 사용하며 validation 점수로 epoch를 고르지 않았다. [S06, S10]

실제 F 학습 receipt에는 8 epochs, 1,120 optimizer updates, 41.296초가
기록되어 있다. 최종 epoch8을 사용했으며 validation 점수가 높은 epoch를
고르는 탐색은 하지 않았다. 이 손실 곡선은 학습 목적함수의 변화로, 일반화
성능의 향상 곡선을 의미하지 않는다. [S06, S10]


3-2-4. 두 단계 label 결합

          ŷ₁(x) = ŷ_E(x) if ŷ_E(x) ∈ {Al3Ni, Al}; otherwise ŷ_R(x)

                 ŷ₂(x) = Al if ŷ_F(x) = Al; otherwise ŷ₁(x)

stage1은 E의 모든 클래스 출력을 통째로 대체하지 않는다. E가 Al₃Ni 또는 Al로
판단한 위치에만 E label을 적용한다. stage2도 F가 Al로 판단한 위치만
덮어쓴다. 신뢰도 threshold나 이번 validation 점수에 따른 추가 규칙은
사용하지 않았다. [S08, S03]




3-3. 성능(필수)


3-3-1. 공식 지표와 독립 재채점

         IoUᵢ,c = TPᵢ,c / (TPᵢ,c + FPᵢ,c + FNᵢ,c), 단 union=0이면 0

               image mIoU = (1/20) Σᵢ₌₁²⁰ [(1/4) Σc₌₁⁴ IoUᵢ,c]

각 이미지에서 네 클래스 IoU를 먼저 평균하고 그 값을 20장에 대해 평균한다.
정답과 예측에 없는 클래스도 0으로 포함하며, 전체 영상을 하나로 합친 global
mIoU는 계산하지 않았다. 100%−image mIoU는 지표의 보수값이며 오분류 픽셀
비율이 아니다. [S01, S07]

                                    [pic]

그림 12. image mIoU의 평균 규칙. 빈 union은 0으로 처리하고 네 클래스 평균
후 이미지 20장을 평균한다. 그림의 수치는 설명용이며 실제 클래스 성능이
아니다. [S01]

R·stage1·stage2의 저장 label PNG 60장을 정답과 다시 대조하여 총 240개
클래스 IoU와 3개 최종 평균이 기존 JSON과 10⁻¹² 이내에서 일치함을 확인했다.
E 단독 점수는 저장된 E 확률에서 원래 동률 우선순위를 유지한 argmax로 새로
계산했다. 이는 추가 학습이나 모델 재추론이 아닌 저장 출력의 평가다. [S07]

않는다. Model364의 중단 보고서(model_results_1006_3)는 최종 점수가 없으므로
완료 실험의 수치로 채우지 않았다. [S11]


3-3-7. test10 제출 산출물의 상태

원본 양식은 test10 예측 마스크 제출을 요구한다. 현재
model_results_20261009_2에는 새 가중치의 valid20 결과가 있으며, 이 실행에서
생성한 test10 결과 폴더는 확인되지 않았다. 따라서 이 보고서는 현재 재학습
모델의 test10 제출 마스크가 완성되었다고 기재하지 않는다. 제공된 test10
입력은 EDA에만 사용했고, 정답이 없으므로 test mIoU를 계산하지 않았다.
[S01–S03]

GitHub fresh 보고서의 test10은 별도 고정 가중치 실행이며 새 R 대비 일치율
98.21783315%가 기록되어 있다. 이는 두 모델 예측 사이의 일치율이지 정답 대비
정확도 또는 test mIoU가 아니다. 과거 다른 모델의 test 마스크를 현재 모델의
제출 결과로 대체하지 않는다. [S09]

⑤ 한계와 추가 연구

첫째, valid20은 개발 과정에서 반복적으로 사용되었고 train과 일부 시편 ID가
겹친다. 따라서 본 점수는 제공된 검증셋의 성능이며 새로운 시편·촬영 조건에
대한 독립 일반화 성능은 아니다. 둘째, 현재 실험은 구성별 고정 seed의 한 번
재학습이다. 소수점 여섯 자리 표시는 계산값을 추적하기 위한 정밀도이며
그만큼 작은 변화가 통계적으로 확실하다는 뜻은 아니다. [S02, S07, S08]

셋째, GitHub 고정 모델과 현재 재학습 결과 사이에는 가중치·환경·학습
난수·선택 과정의 차이가 있다. 현재 R+E가 GitHub fresh R+E보다 낮은 차이를
특정 라이브러리나 normalization 변경 하나의 영향으로 단정할 수 없다. 넷째,
GitHub의 F 조건부 검증 결과와 현재 단일 실행의 작은 평균 이득을 함께
고려해야 한다. [S08, S09]

다섯째, 영상별 손실이 남는다. 현재 stage1의 최악 손실은 −0.541998%p로
GitHub의 영상별 손실 기준 −0.10%p를 만족하지 않는다. 단일 평균값만으로 기존
base를 대체할 근거가 충분하다고 하지 않는다. 여섯째, 현재 새 가중치의
test10 제출 마스크는 본 보고서 생성 범위에서 새로 만들지 않았고, test GT
부재로 성능을 검증할 수 없다. [S07–S09]
