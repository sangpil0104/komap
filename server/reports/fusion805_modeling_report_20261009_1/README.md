# Fusion805 모델링 결과서

2026-10-09 한국 시간 기준 프로젝트 결과와 GitHub 자료를 정리한 확장 보고서입니다.
원본 `모델링결과서.doc`의 필수 목차를 유지하고, 요청에 따라 분량 제한 없이 작성했습니다.

## 문서

- **모델링_결과서_Fusion805.doc**: 실제 Word 97–2003 바이너리 형식.
- **모델링_결과서_Fusion805.docx**: 최신 Word에서 편집하기 위한 동일 내용.
- **모델링_결과서_Fusion805.md**: 그림을 상대 경로로 연결한 Markdown.
- **모델링_결과서_Fusion805.pdf**: 한글·표·그림의 배치를 확인할 수 있는 열람본.

팀명·접수번호·최근 3년 수상경력은 제공되지 않아 `미제공(제출 전 기입)`으로 표시했습니다.
현재 새 가중치의 test10 마스크는 기존 실행 결과에서 확인되지 않았으며, 이 보고서에서
새로 모델 추론을 실행하거나 제출 마스크 완료를 주장하지 않았습니다.

## 그림·표

- `figures/`: 본문 **23개 그림**, 각 PNG(300dpi)와 SVG, 삽입 순서 목록.
- `tables/`: 본문 **24개 표**, 각 Markdown·CSV·PNG, 표 목록.
- `appendix/stage1/`, `appendix/stage2/`: 검증 20장씩 **40개 비교 PNG**.
  문서 부록에는 같은 이미지의 두 단계를 한 페이지에서 비교합니다.
- `tables/project_result_inventory.csv`: 현재 프로젝트에 실제 존재하는 결과서 목록.

표는 Word에서 편집 가능한 표로 삽입했습니다. 표 PNG는 개별 활용용입니다.
그림 파일의 숫자는 자료 ID이며, 본문 그림 번호와의 대응은 `figures/그림_목록.md`를 참고하세요.

## 점수의 범위

현재 재학습 실행: R **80.051924%**, E 단독 **79.542964%**,
Stage1 R+E **80.236507%**, Stage2 R+E+F **80.267268%**.
공식 지표는 valid20의 이미지별 4클래스 IoU 평균이며 빈 union은 0입니다.
GitHub의 원래 고정 가중치 점수와 현재 새 가중치의 점수는 본문에서 구분했습니다.
Stage1이 대표 결과이고 Stage2는 비교용입니다.

## 근거·재생성

- `evidence/`: 독립 재채점, EDA, 픽셀 변화, 실제 실행 시간, GitHub 문서 사본,
  원본 양식, 입력·모델 manifest, 실행 당시 소스.
- `source/`: 보고서 분석·그림·문서·표 생성 코드와 한글 글꼴/라이선스.
- `validation/`: 문서 형식·내부 그림 수·로컬 링크·입력 불변·수치 일치 검사,
  PDF 페이지 점검과 DOC를 다시 열어 만든 검증 PDF.

생성 코드는 conda `komap`에서 실행했습니다. 기존 학습 환경 패키지는 변경하지 않고
보고서 전용 Python/LibreOffice 도구를 `reports/.report_tools_20261009_1/`에 별도로 준비했습니다.
문서 생성에는 `python-docx`, 검증에는 `pymupdf`, 분석·그림에는 NumPy/Pillow/Matplotlib/tqdm이 필요합니다.
DOC/PDF 변환에는 LibreOffice Writer를 사용했습니다. 도구 설치물은 보고서 ZIP에 포함하지 않습니다.

분석 입력은 기존 프로젝트의 절대 경로를 사용하므로 원본 프로젝트를 유지한 상태에서 재생성해야 합니다.
보고서 ZIP에는 모델 가중치·전체 학습 데이터의 중복 사본을 넣지 않았습니다.
현재 가중치는 기존 `results/model_results_20261009_2/selected_model/`에 보존되어 있습니다.

`manifest.sha256.json`은 보고서 산출물의 해시입니다. 이전 모델·학습 소스·결과서는 변경하지 않았습니다.
