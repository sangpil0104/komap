모델 구조와 학습 계보

Model349는 실험·조합 번호입니다. 하나의 새 네트워크가 아니라 여러 학습 계열에서 만든 확률맵을 순차적으로 결합한 결과입니다. 인코더의 ImageNet 사전학습 초기화는 유지했습니다.

항목실제 설정
변경한 요소모든 semantic CE의 클래스 가중치를 제거했습니다. weight=None, 네 클래스에 동일한 가중치입니다. Model62는 loss-mode standard, Model347은 ce-class-weights 인자 없이 실행합니다.
손실과 샘플링CE/Dice 비율, 클래스 평균 Dice, 경계 손실, 경계 BCE pos_weight, 희소 클래스·patch sampling은 유지했습니다. HRNet은 0.5 CE + 0.5 Dice에 경계 보조 손실(weight 1.0)을 더합니다.
데이터와 초기화train 70장 / valid 20장. 데이터 fold·seed·epoch·batch 설정과 ImageNet 초기화를 유지했습니다. 이전 실험의 학습된 체크포인트는 사용하지 않았습니다.
HRNet 입력·최적화patch 512, input scale 2.0, 이미지당 12 samples, batch 4 × accumulation 2. Model336 lr 3e-4, Model347 lr 1e-4 / encoder lr 배율 0.3, weight decay 1e-4.
추론과 후처리기존 계열별 추론·TTA, 클래스별 gamma 탐색, 보정·후처리 경로를 유지했습니다. 예를 들어 257·269 계열은 D4 TTA를 사용하며 전체 모델의 TTA가 동일한 것은 아닙니다.
실행 구성conda komap, 물리 GPU 6·7. 독립 모델·fold를 GPU당 하나씩 실행하는 총 59단계(50 GPU / 9 CPU) 파이프라인입니다.

이전 동일 파이프라인 결과(0930_1): 80.068799%. 이번 결과와의 차이는 -0.028262 %p입니다. 재학습을 포함한 단일 실행 비교이므로 이 차이만으로 가중치 제거 효과를 확정할 수 없습니다.

실제로 선택된 클래스별 조합

클래스 순서는 Al3Ni / Primary Si / Al / Eutectic Si입니다. Model339의 기본 조합에 Model329, Model336, Model347을 이 순서로 반영합니다. γ=0은 해당 추가 전문가를 반영하지 않고, γ=1은 해당 클래스 채널을 그 전문가 값으로 교체하는 설정입니다. 이후 정규화와 기존 후처리가 적용되므로 아래 값은 전체 모델의 단일 혼합 비율이 아닙니다.

평가 지표

이미지별 mIoU = ¼ × Σ(4개 클래스의 TP / (TP + FP + FN))
최종 지표 = ¹⁄₂₀ × Σ(20장의 이미지별 mIoU)
