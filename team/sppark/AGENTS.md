# 프로젝트 작업 지침

- 실험을 위한 소스코드를 빌드할때, 파일의 구조를 수정해도 되니, 이전 결과를 잘 보존하고, 만들어놓은 모델과 그에 대한 소스코드를 바꾸지 않는다.
- 기존 학습 모델, 그 모델에 사용된 소스코드, 이전 실험 결과를 보존한다. 새 실험은 별도 경로에 만들고 기존 파일을 덮어쓰지 않는다.
- 학습·실험 진행률과 경과 시간·예상 남은 시간은 터미널의 `tqdm` 등으로 제공한다.
- 진행률 확인을 위해 localhost 서버나 웹 대시보드를 실행하거나 브라우저 접속을 안내하지 않는다.
- 학습지표는 image mIoU이며, (1 / N) * Σ(i=1 to N) [ (1 / 4) * Σ(c=1 to 4) [ TP(i,c) / (TP(i,c) + FP(i,c) + FN(i,c)) ] ] 으로 계산된다. 이미지 별 mIoU를 먼저 구하고, 그 값을 이미지 20장에 대해 평균하는 방식이다. 예를 들어 나머지 3개 클래스 IoU가 모두 0.8이고, Primary Si는 정답 mask, 예측 mask에 모두 없다면, (0.8 + 0.8 + 0.8 + 0) ÷ 4 = 60% 이런식으로 계산한다. global mIoU는 중요하지 않으니, 구하지 않는다.
학습 시작은 항상 사용자가 한다. 학습 시작하기까지의 과정을 만들어주면 된다.
가상환경은 항상 conda의 komap 가상환경을 사용하며 이 환경에서 실행되게 코드를 만든다.
학습이 끝나면 results 폴더에 model_results_날짜_번호 순으로 폴더를 만들어 그 안에 결과를 담은 md파일과 valid_mask_comparison이라는 폴더를 만들어 그 안에는 valid data마다 2x2의 배치로 왼쪽 상단에는 Original image, 좌측 하단에는 predicted mask, 우측 하단에는 ground-truth mask를 배치해 결과를 비교할 수 있는 사진을 만든다. 오른쪽 위는 틀린 위치만 보여줍니다. 맞게 예측한 픽셀은 흰색이고, 틀린 픽셀은 그 위치의 정답 색으로 표시했습니다. 예를 들어 초록색 오류는 실제로 Primary Si인 부분을 다른 상으로 판단했다는 뜻입니다. 이 사진 위에 해당 사진의 image mIoU와 100% 에서 image mIoU를 뺀 값(100%-image mIoU)를 표시합니다.
