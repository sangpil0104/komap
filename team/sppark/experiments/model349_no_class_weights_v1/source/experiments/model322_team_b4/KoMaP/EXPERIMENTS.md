# KoMaP 상분할 실험 정리

기간 2026-09-17 ~ 09-23 · 서버 RTX 5080 16GB · 코드 `~/komap/code`, 결과 `~/komap/runs`

---

## 1. 과제와 데이터

고탄성 주조용 Al 합금 OM 이미지를 4개 상으로 분할한다.

| 색 | 상 | 면적 비율 | 겉모습 |
|---|---|---|---|
| 갈색 | Al (기지) | 57% | 가장 밝음 (반사율 높음) |
| 파랑 | Al3Ni | 25% | 중간 회색의 길쭉한 막대 |
| 초록 | Primary Si | 9% | 어두운 각진 다각형 |
| 흰색 | Eutectic Si | 7% | 가는 침상 |

- train 70쌍 / valid 20쌍 / test 10장(마스크 없음)
- 이미지는 사실상 흑백(R=G=B), 크기 4~5종(675×480 ~ 1440×1024)
- 사진마다 노출이 크게 달라 같은 상이 어떤 사진에선 회색, 어떤 사진에선 검정
- 시료 번호(A###)가 train/valid에 7개 겹침 → valid 점수가 약간 낙관적일 수 있음
- train A57, valid A71에는 Primary Si가 아예 없음

## 2. 평가 지표

과제 기준은 **image-wise**: 이미지마다 4클래스 IoU를 평균한 뒤, 이미지 수로 다시 평균.

- 이미지에 없는 클래스 처리 규칙은 과제에 없음 → 제외 평균(주 지표)과 1로 처리(참고) 둘 다 기록
- global(전체 픽셀 합산)과는 값이 다름. 3배 확대 모델 기준 **image-wise 78.73 vs global 80.80** — global은 큰 이미지에 가중되므로 판단에 쓰지 않는다. image-wise 장별 편차 57.7~89.0.

## 3. 공통 설정

- U-Net(smp) + ImageNet 사전학습 인코더, 입력은 흑백을 3채널 복사
- 원본 해상도에서 크롭 학습(면적 비례 샘플링), Affine(0.7~1.4배, 임의 회전) · D4 · 밝기/대비/감마 · 블러/노이즈
- 손실 CE + Dice, AdamW, warmup + cosine, bf16
- 추론은 전체 이미지(32배수 reflect 패딩) + D4 8방향 TTA
- **valid로 체크포인트를 고르지 않음** — 마지막 체크포인트만 저장하고 valid는 보고용. 선택 편향 방지.
- 시드 편차: 2배 확대 4시드 0.36(sd 0.16), 3배 확대 3시드 0.51(sd 0.26) → **±0.5 이내 차이는 판단 불가**

## 4. 라운드별 결과 (valid 20장, TTA 포함 image-wise mIoU)

### 1라운드 — 인코더·정규화 (crop 512, 8000 it)

| run | mIoU | Al | Al3Ni | PrimSi | EutSi |
|---|---|---|---|---|---|
| ConvNeXt-S | 76.68 | 92.49 | 71.39 | 89.37 | 55.37 |
| ConvNeXt-S + 이미지별 정규화 | 76.91 | 92.46 | 72.17 | 89.49 | 55.36 |
| **EffNet-B4 (기준선)** | **77.02** | 92.96 | 72.11 | 89.90 | 54.98 |

셋의 차이는 노이즈 수준. 이후 EffNet-B4를 기준선으로 고정. **침상(Eutectic Si) 55가 병목**으로 확인.

### 2라운드 — 문맥·해상도·모델 크기

| run | 변경점 | mIoU | Al | Al3Ni | PrimSi | EutSi |
|---|---|---|---|---|---|---|
| crop768 + 16000 it | 문맥 확대 + 장기 학습 | 77.23 | 93.29 | 72.84 | 89.91 | 54.72 |
| **입력 2배 확대** | crop 1024(시야는 기준선과 동일) | **78.19** | 93.45 | 73.05 | 91.00 | **57.37** |
| ConvNeXt-B | 더 큰 인코더 | 76.63 | 92.60 | 71.41 | 89.48 | 54.91 |
| 위 4개(기준선 포함) 앙상블 | 사전 규칙대로 전부 | 77.98 | | | | |

해상도만 효과. 네 클래스 모두 올랐고 노렸던 침상이 +2.4로 가장 크게 상승.
약한 모델을 섞은 앙상블(77.98)은 2배 확대 단일(78.19)보다 낮음 — 이후에도 반복되는 패턴.

### 3라운드 — 수작업 피처와 위상 손실

가설: 상마다 결정학적 특성이 달라 형태가 다르므로(각진 다각형 / 가는 침상 / 막대), 이를 필터로 뽑아 주면 70장 환경에서 도움이 될 것.

사전 점검(train 픽셀, one-vs-rest AUC, 높을수록 그 상을 잘 가려냄):

| 상 | 흑백 | 릿지 | 고주파 | coherence |
|---|---|---|---|---|
| Al | 0.964 | 0.747 | 0.877 | 0.52 |
| Al3Ni | 0.766 | 0.644 | 0.739 | 0.52 |
| PrimSi | 0.971 | 0.565 | 0.721 | 0.52~0.58 |
| EutSi | 0.856 | **0.902** | **0.917** | 0.53 |

- coherence(구조 텐서 방향 일관성)는 파란 막대를 겨냥했으나 무의미(0.52, 흑백과 결합해도 0.906→0.913) → **큐에 올리지 않고 기각**
- 릿지·고주파는 병목인 EutSi에서 흑백보다 나아 실험 진행

| run | mIoU | Al | Al3Ni | PrimSi | EutSi |
|---|---|---|---|---|---|
| 2배 확대 시드0 (기준) | 78.19 | 93.45 | 73.05 | 91.00 | 57.37 |
| 2배 확대 시드1 (기준) | 78.08 | 93.53 | 73.01 | 90.69 | 57.16 |
| + 형태 피처 [흑백, 릿지, 고주파] | 77.73 | 93.20 | 72.97 | 90.28 | 56.32 |
| + clDice 위상 손실 (클래스 1·3, w=0.5) | 77.72 | 93.02 | **72.49** | 90.65 | 56.79 |

**둘 다 기각.** 픽셀 단위로는 분리력이 있었는데도 최종 성능은 오히려 −0.4. CNN이 이미 뽑고 있던 정보였고, 수작업 채널이 원본 흑백 채널 자리를 차지해 손해였던 것으로 보임. clDice는 노렸던 Al3Ni가 가장 낮게 나옴.

clDice 구현 검증(CPU): 정답 0.000 / 파랑 4px 침식 0.221 / 6px 이동 0.582 / 24px 간격 1px 절단 0.022(메모리 때문에 2배 풀링 후 계산하여 가는 끊김엔 둔감).

### 4~5라운드 — 해상도 한계와 앙상블 포화

| 설정 | 시드별 | 평균 | Al | Al3Ni | PrimSi | EutSi |
|---|---|---|---|---|---|---|
| 1배 (기준선) | 77.02 | 77.02 | 92.96 | 72.11 | 89.90 | 54.98 |
| 2배 확대 | 78.19 / 78.08 / 78.27 / 77.91 | 78.11 | 93.50 | 73.01 | 90.85 | 57.20 |
| **3배 확대** | 78.73 / 79.08 / 78.57 | **78.79** | 94.05 | 74.33 | 91.01 | 57.21 |
| 4배 확대(시야 384px) | 79.01 | 79.01 | 94.15 | 74.82 | 91.01 | 57.65 |

- **3배 > 2배는 확정**: 시드 범위가 겹치지 않고(3배 최저 78.57 > 2배 최고 78.27), 평균차 +0.68이 시드 편차보다 훨씬 큼
- **4배는 3배와 구분 불가**(+0.22 < 편차 0.26). 단 4배는 메모리 한계로 시야가 512→384 원본px로 좁아진 상태에서 얻은 값이라, 해상도 이득이 시야 축소로 상쇄됐을 가능성 있음(더 큰 VRAM 필요)
- 3배의 이득은 주로 Al3Ni(+1.3)와 Al(+0.5). 침상은 57 근처에서 정체

앙상블:

| 조합 | mIoU |
|---|---|
| 2배 2시드 / 3시드 / 4시드 | 78.32 / 78.40 / 78.33 |
| 2배 4시드 + 3배 | 78.59 |
| 3배 2시드 / 3시드 | 79.04 / 79.01 |
| **3배 3시드 + 4배** | **79.12** |

시드를 늘리는 이득은 2~3개에서 포화. 최고 앙상블(79.12)도 3배 단일 최고(79.08)와 0.04 차이로 무의미. **79.0~79.1 구간의 네 가지는 서로 통계적으로 구분되지 않음** → 점수가 아니라 비용·안정성으로 선택해야 함.

### 6라운드 — 4배 시드·EMA·다중 스케일 TTA·시야 복원 시도

| 항목 | 결과 | 판정 |
|---|---|---|
| 4배 확대 시드 0/1/2 | 79.01 / 78.10 / 78.87 → 평균 **78.66** (편차 0.91) | 3배 평균 78.79와 동일 수준. 4배는 이득 없음 |
| EMA 가중치 | 71.04→71.12, 78.10→78.08, 78.87→78.98 | **무효**. 세 실행 모두 ±0.1로 일관성 없음 |
| 다중 스케일 TTA(0.9·1·1.1배) | 3배 79.08→78.97, 4배 79.01→79.00 | **기각**. 추론 비용 3배에 이득 없음(축소 예측이 가는 구조를 뭉갬) |
| 4배 + 시야 512 복원 (crop 2048, bs 1 + 누적 2) | 71.04 (EMA 71.12, BN 재보정 62.10) | **실험 무효** — 아래 참고 |

앙상블: 4배 3시드 78.84 / 4배 2시드(EMA 가중치) 78.65 / **4배 3개 + 3배 3개(6모델) 79.01** — 모두 3배 단일 최고(79.08)를 넘지 못함.

**시야 복원 실험이 무효인 이유**: 16GB 안에서 crop 2048을 넣으려면 배치를 1로 줄여야 했다(smp의 EfficientNet 인코더는 그래디언트 체크포인팅 미지원). 그래디언트 누적으로 유효 배치는 2로 맞췄지만 BatchNorm 통계는 크롭 한 장에서만 계산된다. 학습 손실은 정상(0.32)이었으나 검증은 65~71에서 요동쳤고, 학습 후 BN 통계를 재보정하자 62.10으로 더 나빠졌다 → BN 이동평균의 문제가 아니라 배치 1 학습 자체의 train/eval 불일치. **"4배에서 시야를 512로 되돌리면 어떤가"는 여전히 미해결.** 확인하려면 배치 2를 유지할 수 있는 작은 인코더(EffNet-B0)로 crop 2048 vs 1536 쌍을 돌리거나 VRAM이 더 큰 장비가 필요하다.

## 5. 영상처리 기준선 (Primary Si 단독)

"딥러닝 없이 Otsu만으로 초록 상을 얼마나 잡을 수 있나"를 확인. train에서 파라미터를 고르고 valid로만 평가.

| 방법 | valid IoU (초록 있는 19장) |
|---|---|
| 일반 Otsu(2클래스) + 후처리 | train 38.79로 탈락 |
| **multi-Otsu 4클래스 최저 구간 + 열림(r=3) + 200px 미만 제거** | **80.64** |
| 정답을 보고 이미지별 최적 임계값(오라클, 형태 후처리 없음) | 75.90 |
| **모델(EffNet-B4 1배)** | **89.90** |

- 밝기만으로는 안 됨(39%). 초록 입자와 침상이 둘 다 어두워 분리 불가 → 80%는 Otsu가 아니라 **형태 후처리**의 기여
- 정답을 보고 임계값을 골라도 75.9가 한계 → 밝기 기준의 상한
- 안정성 차이: Otsu 48.6~92.8, 모델 76.3~96.5
- 초록이 없는 A71에서 모델은 0픽셀 예측(정답), Otsu는 오검출 → 20장 평균은 Otsu 76.61

## 6. 결론

1. **이 데이터에서 성능을 움직인 축은 입력 해상도 하나뿐이다.** 77.0(1배) → 78.1(2배) → 78.8(3배) → 78.7(4배, 시야 384px)로 3배에서 포화.
2. 효과 없던 것: 더 큰 인코더(ConvNeXt-B), 문맥 확대(crop 768)와 장기 학습, 이미지별 정규화, 수작업 형태 피처, clDice 위상 손실, 방향 일관성 피처, EMA 가중치, 다중 스케일 TTA.
3. **앙상블은 거의 무의미**하고, 약한 모델을 섞으면 오히려 깎인다(2라운드 77.98, 4라운드 78.59, 6라운드 6모델 79.01 사례). 최고 기록 79.12(3배 3시드+4배)도 3배 단일 79.08과 구분되지 않는다.
4. 남은 병목은 여전히 **Eutectic Si(침상) 57**. 해상도로 55→57까지 올렸으나 그 뒤로는 정체. 다음 시도를 한다면 이 클래스의 라벨 경계 품질 검토나, 시야를 유지한 채 4배 이상으로 올릴 수 있는 큰 VRAM 환경이 후보.
5. 조성·화학 정보를 직접 쓰는 모델은 **데이터에 조성표가 없어 불가**. 합금 번호만으로는 test 10장 중 6장이 미지 합금이라 쓸 수 없음. 대회 측에서 조성표를 받을 수 있다면 조성 조건부 모델이 열린다.
