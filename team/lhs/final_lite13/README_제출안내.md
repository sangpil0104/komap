# A616277 — 고탄성 알루미늄 합금 이미지 상 분할 모델 제출물

최종 모델: 가중치 13개(R 7개 + E 5개 + F 1개)를 결합한 상 분할 모델
검증용(valid) 20장 이미지별 4상 mIoU: **80.779378%**

## 제출 항목과 위치


| 제출 항목                    | 위치                                                                                      |
| ------------------------ | --------------------------------------------------------------------------------------- |
| 최종 공모안                   | `A616277_모델링결과서.pdf`                                                                    |
| 개발 분석 프로그램 소스 코드         | `1_소스코드_실행파일_개발환경/komap_model/` 의 `inference/`(예측), `training/`(학습), `tools/`(입력 변환·채점) |
| 실행 파일                    | 같은 폴더의 `run_predict.sh`(가중치로 예측), `run_retrain.sh`(전체 재학습 → 검증 채점 → 평가용 예측)             |
| 개발 환경 yaml 파일            | 같은 폴더의 `environment.yml` (conda, Python 3.10, PyTorch 2.8 + CUDA 12.8)                  |
| 대회 데이터                   | 같은 폴더의 `data/` (valid 20장, test 10장). 학습용 train 70장은 제출 용량 제한으로 제외                                         |
| 평가용(test) 이미지 예측 마스크 10장 | `2_test_예측마스크.zip`                                                                      |
| 학습된 가중치 13개              | 별도 제출: `<가중치 폴더>/weights/` (R/ E/ F/)                                                   |


## 실행 방법

```bash
cd 1_소스코드_실행파일_개발환경/komap_model
conda env create -f environment.yml && conda activate komap
bash run_predict.sh <가중치 폴더>/weights data/test/images out/test 0   # 가중치 13개로 평가용 마스크 생성
bash run_retrain.sh 0                                                  # 학습용 70장으로 가중치 13개 전체 재학습 후 채점·예측 (train 70장을 data/train/에 넣은 뒤 실행)
```

- `<가중치 폴더>`는 별도 제출한 가중치 폴더의 위치입니다.
- 코드의 모든 경로는 `komap_model/` 기준 상대 경로입니다.
- 가중치 구성, 모델별 학습 코드·시드는 `komap_model/README.md`에 있습니다.

## 평가용 예측 마스크

- 파일 10장: `A107_step1_sample3_mask.png` 등, 원본 이미지 이름의 `_image`를 `_mask`로 바꾼 이름이며 크기는 원본과 같습니다.
- 색상(RGB): Al₃Ni (25,76,153), Primary Si (76,178,76), Al (153,127,76), Eutectic Si (204,204,204)
- 제출 가중치 13개와 `run_predict.sh`로 원본 이미지부터 예측한 결과입니다.

## 검증 결과

- 제출 가중치 13개로 원본 이미지부터 예측: 검증용 mIoU 80.779378%, 평가용 마스크는 제출 마스크와 픽셀 단위로 같음

- 재학습하면 시드·GPU 연산 편차 때문에 가중치가 같아지지 않아, 검증용 점수가 80.779378%와 다를 수 있습니다.
