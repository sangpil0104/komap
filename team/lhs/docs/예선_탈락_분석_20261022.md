# 예선 탈락 원인 분석 (2026-10-22)

최종 제출본 lite13(가중치 13개, valid20 이미지별 4상 mIoU 80.779378%)이 예선을 통과하지 못한 원인을, 남아 있는 실험 기록으로 정리한 문서입니다.

## 먼저 밝혀 둘 한계

- 예선 심사 기준(정량 점수와 결과서 평가의 비중), 우리 test 점수, 순위와 컷 점수는 기록에 없습니다. 아래 내용은 기록으로 확인한 사실과 그에 근거한 추정이며, 원인을 확정한 것이 아닙니다.
- 심사 결과나 test 점수를 받게 되면 이 문서의 추정을 그 기준으로 다시 확인해야 합니다.

## 기록으로 확인한 사실

| 항목 | 내용 |
|---|---|
| 점수 추이 (valid20) | 10/4 Model364 79.94% → 10/8 exh14 80.23% → 10/14 lite13 80.78% |
| 재학습 재현 | 같은 레시피로 처음부터 다시 학습하면 80.47% (시드·GPU 연산 편차) |
| valid 사용 | 결합 비율, 후처리(밝기 구간 보정 포함), fold 선택, 8,093개 조합 전수 탐색, ResNet 단계별 best.pt 선택을 모두 같은 valid 20장으로 결정 |
| 시편 단위 교차 검증 | 채택 후보의 시편 제외 재선택(nested) 효과가 0 근처이거나 구간이 0을 포함 (예: exh14 +0.092%p [−0.12, +0.39], lite23 E 비율 재조정 −0.014%p) |
| 모델 규모 | 가중치 13개 1.95GB, 3단계(R → E → F), RTX 5080에서 이미지당 30~50초, 재학습 약 14시간 |
| 제출 용량 | 제출 한도 100MB를 마지막 날 확인. 코드 zip은 train 데이터를 빼 30.7MB로 맞췄으나 가중치는 1.95GB |
| 오류 구조 | 오류의 88.4%가 경계 1픽셀 이내. Eutectic Si IoU 63%. A71은 정답에 Primary Si가 없어 규칙상 0점이 들어가 최대 75% |

### valid와 test의 차이 점검

- 이미지 크기: test 10장은 모두 train에 있는 4가지 크기입니다. valid에만 1096×780 1장이 있습니다.
- 시편: test 10장 중 7장은 train에 없는 시편입니다. 다만 valid에서 train에 있던 시편 7장(80.57%)과 새 시편 13장(80.89%)의 점수 차이가 없어, "새 시편이라 test에서 크게 떨어졌다"는 근거는 찾지 못했습니다.
- A63 시편은 valid와 test에 함께 있습니다.

## 원인 후보 (가능성이 높은 순)

### 1. 정량 점수 자체가 컷에 못 미쳤을 가능성

- 마지막 2주 동안 valid 기준 +0.8%p를 올렸지만, 상승분 대부분은 기존 모델의 재조합과 valid에서 고른 설정에서 나왔습니다. 시편 단위 교차 검증에서는 그 효과가 거의 남지 않았습니다.
- 그래서 test 점수는 valid 80.78%보다 낮았을 가능성이 높습니다. 재학습 점수 80.47%와 교차 검증 결과를 보면 80%대 초반으로 추정됩니다.
- 다른 팀 점수를 모르므로 이것이 컷 아래였는지는 확인할 수 없습니다. 다만 우리 방식은 10월 초부터 80% 근처에서 정체되어 있었습니다.

### 2. valid 20장 과적합

- 20장으로 수천 번의 비교와 선택을 했습니다. 한 모델을 시드만 바꿔 학습해도 단독 valid 점수 표준편차가 0.48%p(범위 1.07%p)여서, 측정 잡음이 우리가 채택한 개선폭(대개 0.01~0.1%p)보다 컸습니다.
- 사전 기준(평균 손실, 최악 이미지 −0.1%p 이내)을 두고 교차 검증으로 확인하는 절차는 있었습니다. 그러나 최종 결합 비율과 후처리는 결국 valid 20장에서 고른 값입니다.

### 3. 복잡도와 실용성

- 모델 13개, 3단계 결합, 1.95GB, 이미지당 30~50초는 결과서 평가에서 실용성·확장성 감점 요인이 될 수 있습니다.
- 가중치가 제출 한도(100MB)를 크게 넘어, 심사 측에서 재현 확인이 어려웠을 수 있습니다.

### 4. 결과서의 독창성과 해석

- 결과서의 중심은 앙상블 설계(상별 결합, 덮어쓰기, 보정기)였습니다. 소재 관점의 해석(상 면적비, 입자 크기, 경계 품질)은 4장 추가 분석에 일부만 들어갔습니다.
- 심사가 아이디어·활용 가능성 비중이 크다면, 점수 대비 설명력이 약했을 수 있습니다.

## 작업 방식에서 본 교훈

- **정확도보다 정리에 시간이 많이 들어갔습니다.** 10월 둘째 주 이후 작업의 상당 부분이 경량화(23개 → 13개), 재현 패키지, 검증, 문서 정리였습니다.
- **기각된 정확도 실험이 많았습니다.** TTA, 축척 변경, TENT 확장, 픽셀 보정기, Lovász, 경계 손실, 증류, fold 공유 등은 대부분 0 또는 음수였습니다.
- **제출 요건을 늦게 확인했습니다.** 제출 용량 100MB 같은 요건은 처음에 확인해 모델 크기 상한으로 삼았어야 했습니다.
- **valid 20장을 개발과 최종 판단에 함께 썼습니다.** 독립 판단용 데이터가 없었습니다. 다음에는 train의 시편 단위 OOF를 주 지표로 쓰고, valid는 마지막 확인에만 쓰는 편이 안전합니다.
- **경계 1픽셀 오류가 대부분이었습니다.** 남은 개선 여지는 라벨 수준의 경계 정밀도 쪽이었습니다. 구조 추가보다 경계 학습이나 라벨 잡음 처리에 더 일찍 집중했어야 합니다.
