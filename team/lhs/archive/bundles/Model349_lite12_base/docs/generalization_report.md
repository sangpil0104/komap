> 이 보고서 작성 후 2026-10-08 사용자 결정으로 12개판을 후속 실험 base로 지정했다. 아래 감사 결과와 일반화 미확인 판정은 그대로 유지한다. 과거의 기본판 유지 권고는 당시 판정 기록이다.

# 12개·10개 FP16판 일반화 가능성 검증 결과

## 결론

**독립 일반화 개선은 두 후보 모두 미확인이다.** 정답이 있는 독립 표본이 없어 현재 가중치의 새 데이터 정확도를 검증할 수 없다. 대신 데이터·학습 이력 감사, 기존 valid의 조건부 재표본화·그룹 제외 분석, 두 후보의 실제 test10 원본 추론을 완료했다.

현재 자료에서는 12개판이 10개판보다 국소 손실과 그룹 민감도가 작다. 12개판은 탐색 후보로 유지하고, 10개판은 기존 이미지 손실 기준 초과로 기각 상태를 유지한다. 기존 기본판·릴리스는 교체하지 않는다.

## 데이터와 독립성

- train 70장/59 specimen, valid 20장/19 specimen, test 10장/10 specimen. 정답은 train/valid에만 있다.
- train-valid specimen 중복: A125, A153, A181, A191, A40, A55, A7. 이미지의 A숫자 ID는 기존 group CV 생성 코드의 specimen 정의와 일치한다.
- train70과 specimen이 겹치지 않는 valid 부분집합은 13장/12그룹이다. 이 13장도 원래 valid 탐색에 사용됐으므로 독립 holdout이 아니다. 또한 가중치 학습 이력 추적이 불완전해 모든 upstream 학습/선택의 미노출을 인증하지 않는다.
- test 중 train/valid와 specimen이 겹치지 않는 것은 6장이다. 나머지 4장은 A167/A51/A87(train), A63(valid)와 그룹을 공유한다.
- split 간 동일 디코딩 RGB 이미지 중복: {"train_valid": 0, "train_test": 0, "valid_test": 0}. 파일 SHA와 디코딩 픽셀 SHA를 모두 기록했다.

## 조건부 품질 안정성

주 비교는 같은 FP16 저장·TENT5·OpenCV2인 14개판이다. 12개/10개 후보·계수·후처리는 동결했고 결과를 보고 다시 고르지 않았다. 지표는 이미지별 네 클래스 IoU 평균의 이미지 평균, 없는 클래스 및 empty union=0이다. PNG/GT를 다시 채점하고 기존 metrics와 1e-12 이내 일치를 확인했다.

specimen을 복원추출하고 그룹 내 모든 이미지를 포함한 image-weighted paired cluster bootstrap 20,000회, seed=20261008, percentile 95% 구간이다. 이는 **이미 후보를 고른 valid에 조건부인 표본 변동 진단**이다. 다중 탐색·후보 선택 편향을 교정하지 않았으므로 새 데이터 성능의 신뢰구간이나 선택 후 유의성 검정으로 해석하지 않는다.

train70과 specimen이 겹치지 않는 부분에서 12개판 구간이 0 위에 있더라도 그 부분집합은 후보 선택에 노출됐고 전체 학습 이력도 완전히 인증되지 않았다. 따라서 독립 일반화 개선의 증명이 아니다.

## 그룹 제외 민감도

| 후보 | 개선/악화 이미지 | 한 specimen 제외 시 평균 변화 범위 | 가장 영향 큰 제외 그룹 | 제외 후 평균 변화 |
|---|---:|---:|---|---:|
| cpu2_fp16_12 | 11/9 | [+0.0113918, +0.0679356]%p | A71 | +0.0113918%p |
| cpu2_fp16_10 | 11/9 | [-0.0155908, +0.0680794]%p | A71 | -0.0155908%p |

그룹 제외는 재훈련 cross-validation이 아니다. 기존 마스크의 평가 표본을 제외한 민감도 분석이며 모델 선택에 사용하지 않았다. 12개판의 평균 변화는 한 그룹을 제외해도 양수이지만 전체 bootstrap 구간은 0을 포함한다. 10개판은 한 그룹을 제외하면 전체 평균 변화가 음수가 되어 상승이 일부 그룹에 더 의존한다.

## 기존 OOF를 전체 후보 검증으로 사용할 수 없는 이유

- 현재 서버의 CV symlink와 group manifest는 specimen 분리와 70장 exactly-once heldout partition을 만족했다. 그러나 배포 bundle의 fold args는 추론 설정만 포함하고 train_splits 기록은 없다.
- 현재 학습 출력의 checkpoint를 동결된 FP16 checkpoint와 CPU에서 tensor key/shape/값(저장 dtype으로 변환)을 비교했다. 파일 SHA 차이뿐 아니라 텐서 불일치가 있으면 동일 모델의 OOF로 인정하지 않았다.

| 학습 출력 | fold | 파일 SHA 동일 | FP16 저장 텐서 동등 | 불일치 키 수 |
|---|---:|---|---|---:|
| 326 | 1 | False | False | 655 |
| 329 | 1 | False | False | 655 |
| 326 | 2 | False | False | 655 |
| 329 | 2 | False | False | 655 |
| 326 | 3 | False | False | 655 |
| 329 | 3 | False | False | 655 |
| 326 | 4 | False | False | 655 |
| 329 | 4 | False | False | 655 |
| HRNet336 | — | False | False | 1719 |

- 이 불일치는 기존 릴리스나 이번 후보가 손상됐다는 판정이 아니다. 후보 자체의 가중치/설정 해시는 실행 전후 일치했고, 이 감사는 현재 학습 출력의 이력을 동결된 배포판에 연결할 수 있는지 확인한 것이다. 불일치 원인은 현재 증거만으로 확정하지 않는다.
- 기록된 원래 group-CV 분할을 적용해도 12·10개판 모두 329의 네 fold를 함께 사용하므로 train70 각 이미지는 세 멤버의 훈련에 포함된다. 해당 이미지의 heldout fold 하나만 고르면 배포 후보가 달라진다. 그 단일-fold OOF를 12·10개 전체 성능으로 보고할 수 없다.
- HRNet의 현재 args와 저장소의 참조 훈련 코드도 train 전체 사용을 나타낸다. 참조 코드는 실제 동결 checkpoint의 실행 이력 인증이 아니며 현재 출력과 배포 텐서의 차이를 함께 기록했다.
- 따라서 기존 train70을 전체 후보에 추론하거나 기존 OOF 캐시를 결합해 누수 없는 일반화 점수로 표시하지 않았다. 현재 자료로 고정된 배포판의 strict OOF는 확인되지 않았다.

## 판정과 남은 검증

- **12개판:** 기존 valid의 점수 상승은 재현됐고 한 specimen을 제외해도 평균 변화는 양수다. 그러나 전체 조건부 구간은 0을 포함하고 선택 편향·학습 이력 추적 불확실성이 남아 있다. 일반화 개선은 미확인, 탐색 후보로 유지한다.
- **10개판:** 전체 구간이 0을 포함하고 한 그룹 제외 시 상승이 사라진다. 14개 FP16 대비 최악 -0.2297681%p(기존 lite15 대비 -0.2232411%p)로 기존 0.10%p 손실 한도를 넘는다. 기본판 채택을 권하지 않는다.
- 독립 일반화 검증에는 후보 동결 후 선택에 쓰지 않은 정답 specimen이 필요하다. 지금은 데이터가 100장뿐이라 이 조건을 충족하지 못했다.
- 추가 데이터 없이 보완하려면 90개 정답 이미지에서 specimen 단위 outer fold를 먼저 고정하고 모든 segmentation checkpoint·초기화 계보·priors·calibration·후처리 선택을 outer holdout 밖에서 재학습하는 평가를 설계할 수 있다. 이는 현재 checkpoint의 독립 검증이 아니라 새로 학습한 고정 경량화 절차의 교차검증이며, 기존 90장으로 이미 선택한 설계 편향이 완전히 사라지는 것도 아니다. 이번에는 이를 임의로 실행하지 않았다.
