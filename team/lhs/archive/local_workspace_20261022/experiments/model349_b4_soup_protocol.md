# B4 가중치 결합 사전 고정 평가

작성 시점: fold 1의 합성 체크포인트 OOF 결과 확인 후, fold 2-4의 OOF 결과 확인 전.

목적: Model349 경로에서 서로 다른 두 EfficientNet-B4 4-fold 계열(326, 329)을 fold별 가중치 평균 체크포인트 4개로 합쳐 추론 체크포인트 4개를 줄일 수 있는지 평가한다. 기존 322 경로와 Model183 기초 캐시는 별개다.

고정된 후보는 같은 fold의 326·329 state_dict를 `0.5:0.5`로 평균하고, 정수형 상태는 329를 택한다. 입력 설정은 329의 `image_global`/`zcdf3`/`target_width=4000`, 추론은 원래와 같은 D4 TTA다. 혼합률·전처리·후처리는 아래 결과를 보고 다시 조정하지 않는다.

평가 순서:

1. 남은 fold 2-4의 held-out train OOF를 같은 방식으로 생성한다.
2. 70장 모두에서 기존 326·329와 합성 모델의 공식 `empty-union=0` image mIoU를 동일 이미지로 비교한다. fold별 차이도 보고한다.
3. OOF에서 합성 모델이 329 단독보다 낮지 않고, 네 fold 중 적어도 세 fold에서 높으며, 어떤 fold에서도 0.5%p보다 많이 낮지 않을 때만 20장 valid에 한 번 적용한다.
4. valid에서는 기존 349의 326·329 두 소스를 합성 모델 한 소스로 대체한 **사전 고정 경로**만 평가한다. 공식 349 raw valid 점수 이상이어야 성능 보존 후보로 남긴다. valid 20장은 후보 계수 재탐색에 쓰지 않는다.

이 조건을 통과해도 기존 349는 이미 valid 반복 탐색의 영향을 받았고 test 정답이 없으므로 독립 일반화가 증명되는 것은 아니다. 통과하지 못하면 가중치 평균 방식은 채택하지 않는다.
