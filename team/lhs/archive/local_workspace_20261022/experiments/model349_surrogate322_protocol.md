# Model322 확률 소스 대체 실험 사전 고정

목표는 Model349에서 Model322의 EfficientNet-B4 4-fold 추론을 제거하되, Model322가 공급하던 확률 채널을 이미 필요한 Model326·329의 출력과 가벼운 회귀로 복원하는 것이다. Model183 기초 캐시와 나머지 소스는 변경하지 않는다.

회귀 입력은 326·329의 4-class 확률 8개와 절편이다. 목적값은 322의 4-class 확률이다. 70장 train OOF의 각 이미지에서 균일 픽셀 5,000개와 322 예측 클래스별 픽셀 1,250개를 추출하고 고정 ridge 계수 0.001로 선형 회귀한다. 출력은 `[1e-6,1]`로 자른 뒤 네 클래스 합이 1이 되도록 정규화한다. train/valid 정답 마스크는 회귀 적합에 사용하지 않는다. valid 예측은 모델 선택이나 계수 조정 전에 한 번만 생성한다.

검증 순서:

1. 네 train fold에서 나머지 세 fold로 회귀를 적합하고 held-out fold에서 322 확률에 대한 MAE를 측정한다. 326을 그대로 322 자리에 놓은 MAE를 기준으로, 전체 이미지 평균이 낮고 4 fold 중 최소 3 fold에서 낮을 때만 다음 단계로 진행한다.
2. 통과하면 train 70장 전체로 회귀를 한 번 적합해 valid 20장의 322 대체 확률을 만든다. 기존 349의 나머지 계수와 소스는 고정한다. 공식 empty-union=0 image mIoU가 원래 349의 79.9095189% 이상일 때만 **raw valid 보존 후보**로 표기한다.
3. 이 경로는 valid를 이미 여러 번 사용한 349에 붙는 후보이므로, 성공해도 test 일반화 보증으로 취급하지 않는다. 독립 제출 또는 새 평가 자료에서 재확인이 필요하다.

실험 코드는 [`model349_surrogate322_train.py`](model349_surrogate322_train.py)다.
