# 기존 HR392 확률의 보완성 탐색

기존 Model401에서 생성한 원본 valid20의 HR392 seed1·seed2 전체 4-fold 평균 확률을 재사용한다. 기존 Model401 자체의 valid 79.41817%와 train-OOF 결과를 읽은 뒤 설계한 탐색으로 확증·독립 일반화 검증이 아니다. 새 학습이나 GPU 추론을 시작하지 않는다. 원본 확률/코드/가중치를 변경하지 않는다.

현재 base14의 HR336 입력 확률을 새 HR392 두 seed 평균과 혼합한다. 두 seed와 8개 fold를 모두 동일 비율로 사용하며 개별 fold/seed를 선택하지 않는다. 결과를 보기 전에 후보를 고정한다: 혼합 강도 0.25/0.5/1.0 × (전체 4클래스 또는 Eutectic Si 채널만). 기준 강도0을 포함한 총7개다. 다른 구성·계수·후처리·고해상도 라우팅을 유지한다. Eutectic 채널 혼합 후 별도 확률 정규화를 추가하지 않는다(기존 클래스별 치환과 동일).

서버 Model401 inference manifest의 40개 확률 SHA를 전부 확인하고 복사 후 다시 대조한다. 팀 순서 [Al, Al3Ni, Primary Si, Eutectic Si]를 base 순서 [Al3Ni, Primary Si, Al, Eutectic Si]로 바꾼다. native 크기/20 이미지 ID/유한 값/정규화 합을 확인한다. 기준 cached20의 모든 클래스 IoU를 기존 base replay와 정확히 재현해야 후보 점수를 사용한다.

채점은 이미지별 4-class IoU 평균을 20장 평균하며 빈 union=0이다. 점수와 이미지·클래스별 변화, 조건부 그룹 bootstrap 및 이 고정7개 후보 안에서 시편 제외 선택 진단을 보존한다. 이들은 반복 valid 탐색 지표이며 새 시편 성능 추정으로 주장하지 않는다. 최고 후보만 전체 기존 predict 경로로 다시 확인한다. 저장 확률의 조합 성적을 전체 새 모델 원본 재추론 성적으로 부르지 않는다. 가중치 수/실제 시간 개선 주장도 하지 않는다. 유의미한 후보라면 추후 원본 입력부터 재현하는 별도 실행이 필요하다.
