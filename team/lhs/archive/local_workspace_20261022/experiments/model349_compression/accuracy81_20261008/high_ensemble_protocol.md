# 고해상도 soft ensemble 탐색

기존 base14는 이미지 통계에 따른 고해상도 경로 하나를 선택한다. 저장 확률의 전체 고해상도 경로를 사용하는 soft ensemble이 이 선택에 따른 변동을 줄이는지 검토한다. 결과를 읽기 전에 아래9개 후보를 고정한다. 반복 사용한 valid 탐색이며 독립 일반화 평가가 아니다. GPU 추론·학습을 추가하지 않는다.

경로 집합은 현재 bundle에 포함된 restart51/model109/seed456/pairwise의4개 또는 EMA까지 포함한5개다. 각 집합을 arithmetic probability mean 또는 geometric probability mean(clip1e-7 후 로그평균, class 합1로 정규화)으로 통합한다. 기존 routed high와 통합 high를 0.5 또는1.0 비율로 혼합한다. 2집합×2평균×2강도=8개에 기준 routed high1개, 총9개다. 개별 모델/이미지/클래스 계수를 따로 고르지 않는다. 기하평균은 의견 일치를 강화하므로 오류 공유 시 악화될 수 있으며 효과를 가정하지 않는다.

base14의 다른 분기·fold·클래스 계수·TENT5·이미지 후처리는 모두 유지한다. cached 기준80 IoU가 기존 best14 replay와 정확히 같고 최고 후보도 원래predict에서 확인해야 한다. 공식 산식은 이미지별4class IoU 평균 후20장평균, 빈union=0이다. 결과는 캐시 조합 탐색 성적으로만 보고하고 원본 입력 전체 재추론/독립 재현/일반화 성적으로 주장하지 않는다.

평균·클래스별·이미지별 변화, 조건부 그룹 bootstrap, 이9개 후보 범위의 시편 제외 선택 진단을 보존한다. 기존4경로 모두를 모든 이미지에 돌리는 시간은 현재하드라우팅보다 증가할 수 있으며 실제 시간을 측정하기 전 단정하지 않는다. EMA 추가 구성은 새checkpoint1개가 더 필요하다. 기존 모델/가중치/릴리스/타 작업은 변경하지 않는다.
