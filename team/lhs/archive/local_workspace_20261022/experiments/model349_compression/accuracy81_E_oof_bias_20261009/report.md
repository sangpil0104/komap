# E 클래스 편향 train70 OOF 검사

B4 + HRNet 2시드의 고정 E에 Al3Ni·Al·Eutectic Si log-odds 편향 각각 −0.1 / 0 / +0.1을 적용한 27개 설정을 비교했다. 네 grouped fold마다 나머지 세 fold에서 보정 값을 고르고 제외한 fold에서 평가했다.

기존 E OOF 79.9858620%를 정확히 재현했다. 보정의 fold 제외 값은 79.9824486%, 기준 대비 −0.0034134%p다. 사전 +0.10%p / 3개 fold 개선 / 최악 fold −0.10%p 기준을 통과하지 못해 기각했다. 전체 70장에 맞춘 선택 값은 검증값으로 사용하지 않는다.

저장된 70장 클래스 IoU에서 점수를 재계산해 일치했다. train70 GT만 사용했고 valid/test GT 및 GPU는 읽거나 사용하지 않았다. 부모 확률 SHA는 불변이며, 진행 중인 1단계 원본 영상 재추론 설정과 기존 base는 바꾸지 않았다.
