# Model349 경량화 재개 감사 결과 (2026-10-08)

## 판정


D4 배치 후보는 사전 탐색 채택 기준을 통과하지 못했다. 저장 크기 개선과 성능·시간 판정은 구분한다.

valid20 원본 영상 재추론과 반복 시간의 재현 결과다. 이 valid를 반복 사용했으므로 독립 일반화 검증이나 test 점수 유지 근거로 해석하지 않는다. 기존 릴리스·원본 가중치·미완료 산출물은 덮어쓰지 않았다.

## 감사와 실행 조건

- GPU 사용자 매뉴얼 전체를 읽었다. GPU6은 타 컨테이너의 작업(PID 549152, 3328 MiB)이 점유하여 사용하지 않았다. 비어 있던 P100 GPU7 한 장에서 기준과 후보를 순차 실행했다.
- GPU6 지정 기존 프로토콜을 GPU7의 동시기 기준 비교로 보완했으며, 결과 전 문서에 기록했다. flock·현재 프로세스 확인·GPU 점유 재확인으로 중복을 막았다. 다른 사용자 작업은 조작하지 않았다.
- 과거 FP16 TENT5는 5개 component 모두 20장·100개 확률을 완료했고 fusion에서 마스크 1장만 남아 있었다. 별도 경로로 CPU fusion을 복구했다(80.0655029%). 전체 시간은 알 수 없으므로 null이며 속도 근거에서 제외한다. 중단 원인은 로그만으로 확정하지 못했다.
- 과거 TENT3/12에는 완료·부분 산출물이 없었다. 새 경로에 원본 영상부터 실행했다. 이전 고정 PID 대기 큐는 재사용하지 않았다.
- 초기 lite15는 614.73초였지만 CPU load와 width4000 B4 지연이 컸다. 이 실행과 과거 366.56초 단회만으로 후보 속도를 판단하지 않는다.

## 조건부 HRNet FP16 autocast

## 추가 의견 검토

10개 계수 0.7~1.0의 평균 80.09~80.12%와 train70 교사 82.9768%(Eutectic Si 65.1677%)는 파일과 일치했다. 하지만 0.8의 최악 이미지 -0.2262%p, 1.0의 -0.6709%p 때문에 평균만으로 추천하지 않는다. 326 Primary Si가 뒤에서 덮어써져도 중간 전체 확률 정규화가 있으므로 완전한 Al3Ni 단독 역할이라고 단정하지 않는다.

증류 학생의 77.5~78.5%는 미측정 예상이다. train70 점수만으로 교사의 암기 여부를 판단할 수 없고, 추가 무라벨 자료가 없어도 GT+soft target 증류는 가능하다. 다만 현 자료는 단일 학생의 80% 유지 근거가 부족하다. B4 fold1 기준 차이는 약 3.12%p, HRNet 단일 출력 기준은 약 1.91%p다. 이번에는 학생 훈련을 시작하지 않았으며 valid/test를 훈련에 사용하지 않았다. [상세 검토](review_notes.md).
