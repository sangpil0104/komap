# 추가 탐색·증류 의견의 파일 기반 검토

## 10가중치 축소

`results/eval_l14.json`의 동일 저장 확률 탐색 기준 lite14는 80.0651646760%다. 이 값은 원본 영상 lite14 80.0650398575%와 다르며, 그대로 확정 성적으로 사용하지 않는다.

| 저장 확률 조합 | image mIoU | lite14 대비 최악 이미지 변화 |
|---|---:|---:|
| 326 제거, 계수 유지 | 79.9684838554% | -1.6961%p |
| 326 제거, gamma329 Al3Ni=0.7 | 80.0886168842% | -0.1767%p |
| 326 제거, gamma329 Al3Ni=0.8 | 80.1188778107% | -0.2262%p |
| 326 제거, gamma329 Al3Ni=1.0 | 80.1126245362% | -0.6709%p |
| 269 제거 | 80.0229937806% | -0.8656%p |

평균 80.09~80.12%라는 설명은 파일과 일치한다. 그러나 계수가 넓은 구간에서 평균을 유지한다는 것이 이미지별 안정성을 뜻하지 않는다. 기존 FP16/TENT3 사전 기준의 최대 이미지 손실 0.10%p를 적용하면 이 세 계수 모두 저장 확률 단계에서는 초과한다. 이번에는 0.8 하나만 사전 고정하여 실제 326 가중치 4개와 forward를 제거한 FP16 10개판을 원본 영상부터 재실행한다. 이를 valid 탐색 재현으로 표시하며, 결과에 맞춰 계수를 다시 고르지 않는다.

`gamma329 Primary Si=1.0`은 마지막 Primary Si 교체가 329라는 의미다. 그러나 `model335_exhaustive_b4_route_search.make_mixed`가 Primary → Al3Ni → Eutectic 순서로 교체하고, `model198_fast_branch_search.replace_classes`는 매 교체 뒤 네 클래스 전체를 정규화한다. 앞선 326 Primary 확률이 중간 정규화와 뒤 클래스 혼합에 간접 영향을 줄 수 있어, 326이 수학적으로 Al3Ni에만 영향을 준다고 단정하거나 329 Al3Ni 계수 조정과 완전 동등하다고 주장하지 않는다. 최종 원본 재추론 점수를 근거로 판정한다.

force_restart51은 기존 -0.0454619%p로 평균 사전 기준 0.02%p를 초과해 기각됐으며 이 결론을 바꾸지 않는다. 269 제거와 fold 추가 선택도 진행하지 않는다. 과거 예약된 fold326 1·3의 12개판은 중단 실험을 마무리하는 진단으로만 평가한다.

## 증류

`results/lite14_train70_metrics.json`의 image mIoU는 82.9767927832%, Eutectic Si image-mean IoU는 65.1677486978%다. 이는 교사의 train 마스크 성능이며, 암기 여부나 독립 일반화를 판정하는 실험이 아니다. 교사 오류가 soft target에 포함된다는 우려는 타당하다. 실제 학생 학습을 시험한다면 GT supervised loss와 교사 soft target을 함께 사용하고 specimen-group held-out 평가를 분리해야 한다.

`results/eval_single.json`의 같은 후처리 단일 출력 진단:

| 출력 | valid image mIoU |
|---|---:|
| B4 329 fold1 | 76.9496069027% |
| HRNet336 | 78.1520247310% |
| B4 329 4-fold | 78.6822970110% |
| lite14 저장 확률 기준 | 80.0651646760% |

B4 fold1 학생을 기준으로 한 차이는 약 3.12%p, HRNet 단일 출력 기준은 약 1.91%p다. 이 표는 기존 모델의 출력 진단이지 증류 학생이 도달할 수 있는 상·하한이 아니다. 77.5~78.5% 예상은 미측정 가설로 표시한다. 추가 무라벨 영상이 없어도 train GT와 teacher 확률을 함께 쓰는 증류는 가능하지만, 이 자료만으로 단일 학생이 80%를 유지할 것이라는 근거는 부족하다. 현재 과제는 작은 앙상블과 실제 추론 병목 검증이므로 새 학생 학습은 후순위로 둔다. valid20이나 test10을 학생 훈련용으로 전용하지 않는다.

## 사전 검토 이후 원본 재추론 확인

326을 실제로 제거하고 Al3Ni=0.8로 고정한 10개 FP16판의 valid20 공식 image mIoU는 **80.1188236010%**였다. 이번 lite15 원본 재추론 대비 평균 +0.0543993%p였지만 A153_step3_sample3는 **-0.2232411%p**로 사전 이미지 손실 한도를 초과해 기각했다. 저장 확률의 평균 점수 재현과 채택 가능성은 다르다. 계수를 다시 탐색하지 않았다. 시간 345.08초는 단회 진단이며 확정 속도 개선으로 사용하지 않는다. 모든 이미지·클래스 변화는 comparison.json에 있다.

TENT3 역시 공식 평균 80.0486797263%, 평균 변화 -0.0157446%p, A11_step1_sample4 최악 -0.2007161%p로 기각했다. 12개 fold 선택안은 80.1255610462%와 최악 -0.0930182%p로 품질 한도는 통과했으나 선택 편향과 단회 시간의 한계로 기본판에 채택하지 않았다.
