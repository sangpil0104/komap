## 시편 제외 평가의 누수

C단계는 전체 valid 정답으로 A 상위50/B 상위40을 먼저 고른다. analyze_exh.py의 시편 제외 선택은 이 전역 shortlist를 포함한 A+B+C 안에서만 수행한다. 제외 시편이 shortlist 작성에 이미 영향을 주었으므로 엄밀한 중첩 LOSO가 아니다. 재계산한 전체 +0.08930%p [−0.12342,+0.37963]는 같은 누수 있는 절차의 재현이다. 원문에서 “새 시편” 성능으로 제시한 수치는 새 이미지 평가가 아니다.

제외 시편마다 나머지 시편으로 top50/top40을 다시 구성하면 C에 없는 교차 조합이 80~1,832개 생긴다. 따라서 저장된 C만으로 올바른 전체 파이프라인 LOSO 결과를 확정할 수 없다. 각 제외 반복에서 후보 추림과 교차 채점을 모두 다시 해야 한다. 그 경우에도 기존 학습 시편 중복과 반복 valid 노출 때문에 독립 신규 데이터 성능이 되지는 않는다.

고정 격자 A+B만 사용하면 C shortlist 누수는 없으며 −0.22808%p [−0.67912,+0.04159]를 재현한다. 이는 fold 선택 안정성을 지지하지 않는다. 같은 valid 재사용, 모델 학습 이력, 시편 중복의 한계는 남는다. 가중치 예산별 A+B+C 신뢰구간도 C shortlist 누수를 공유한다.
