## 결합 계수 CPU 탐색

기존 base 확률을 고정한 탐색 채점이다. gamma0.5의 base 점수는 정확히 재현했다. 아래 둘은 국소 손실 gate 초과로 기각했으므로 원본 영상 재추론 후보로 올리지 않았다.

| Al3Ni gamma329 | 탐색 mIoU | 평균 변화 | 최악 이미지 변화 |
|---|---:|---:|---:|
| 0.6 | 80.1397563% | +0.0141953%p | -0.1647439%p (A153_step3_sample3) |
| 0.7 | 80.1562526% | +0.0306915%p | -0.3167205%p (A153_step3_sample3) |

Al3Ni 클래스 계수를 올려도 `replace_classes`가 네 클래스 확률을 다시 정규화하므로 다른 클래스가 독립적으로 보존되는 것은 아니다. gamma0.6에서 A153 Eutectic Si IoU는 약 −0.770925%p로 악화했다. 평균만 높아진 조합을 성능 개선판으로 채택하지 않았다.

실행 전 동결한 선택 코드에서는 base12와 기존 lite15의 gate를 모두 통과해야 반복 시간/후속 test 후보로 올리도록 구현했다. 프로토콜 본문의 “품질 통과”는 이 이중 조건을 명확하게 풀어 쓰지 않아 문구가 불완전했다. TENT4는 base12 기준만 통과했고 lite15 대비 A74에서 −0.1177126%p로 기존 국소 손실 한도를 넘었다. 따라서 이번 단계에서는 반복 시간과 test를 시작하지 않았다. TENT4가 base gate 자체에 실패했다고 표시하지 않으며, 탐색 단회 시간을 속도 개선 근거로 쓰지 않는다.

## 한계와 사용 상태

계수 후보는 동일 valid의 저장 확률로 선택한 뒤 원본 재추론했다. 재추론은 구현 재현이지 독립 성능 확인이 아니다. 고해상도 seed 대체도 밝기별 모델 선택을 추가 탐색한 것이므로 신규 자료에서 손실을 보증할 수 없다. 100장만 있으며 train-valid specimen 중복과 동결 가중치 학습 이력의 불완전성은 기존 일반화 감사와 동일하다.

12개 base는 자동 교체하지 않는다. 통과한 새 후보를 별도 실험 버전으로 보관하고 사용자에게 결과를 보고한다. TENT 변경은 계산량에 영향을 주며 고해상도 밝기 모델 한 개 제거는 저장량만큼 전체 순전파 시간을 줄이지 않을 수 있다.
