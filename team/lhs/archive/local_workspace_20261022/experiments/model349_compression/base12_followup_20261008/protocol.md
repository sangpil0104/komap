기준은 `cpu2_fp16_12`: 326 fold1·3 / 329 4-fold / HRNet336 / native269 / high 후보4, FP16 저장·FP32 로드, TENT5·OpenCV2. 공식 valid20 image mIoU, 이미지별 4 IoU 평균 후 20장 평균, absent/empty union=0. 원본349와 lite15 대비 변화도 기록한다.

범위는 아래 세 가지로 한정한다. 새 fold 선택·재훈련·test 기반 계수 선택은 하지 않는다.

1. **11개 고해상도 seed 대체**: `restart59_aspp768_seed456` 체크포인트와 로드를 제거하고 해당 밝기 구간을 `restart61_pairwise_margin`으로 대체한다. 다른 밝기 구간·route·TENT5 동일. 기존 restart51 대체는 A74에서 손실 기준을 넘었으므로 별도 기존 모델 대체 가능성을 확인한다. 밝기 구간을 새로 맞추지 않는다. 원본 valid20부터 전부 재추론한다.
2. **12개 결합 계수**: gamma329의 Al3Ni만 0.5(base) / 0.6 / 0.7로 비교한다. 기존 base 저장 확률을 고정해 CPU 탐색한다. 평균/국소 손실 기준을 통과한 개선 후보 중 평균 최고를 하나만 원본 valid20부터 재추론한다. 동률이면 원래 0.5에 가까운 값을 선택한다. 저장 확률 채점은 탐색이지 확정 재추론 성적이 아니다.
3. **12개 TENT4**: TENT steps 5→4만 변경하여 원본 valid20부터 재추론한다. 과거 TENT3는 국소 손실 기준 초과였으므로 반복하지 않는다.
