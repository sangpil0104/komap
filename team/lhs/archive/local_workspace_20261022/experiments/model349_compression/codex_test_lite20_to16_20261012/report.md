# test10 lite20 → lite16 변경 영역 검토

기존 최종 예측만 수집하여 비교했다. lite20 / lite19a / lite18 / lite18h / lite16_b413을 포함한다. lite18과 lite18h는 서로 다른 가지이며, 숫자순 단일 축약 경로로 해석하지 않는다. lite17 결과는 이번에 확인하지 못했다. 입력 SHA 일치 확인. GPU 작업 재실행 없음.

## 판단

10장별로 변경 밀도가 높은 최대4개220×220영역을 원본 및 모든 버전과 확대 대조했다. 검토한 영역에서는 큰 입자의 전반적 형태가 유지되며 대규모 영역 붕괴는 보이지 않았다. 미세 구조의 경계와 작은 영역의 클래스는 바뀐다. 원본 회색조만으로 모든 상의 정답을 판별할 수 없으므로 정확도 상승/하락은 주장하지 않는다.

lite20→lite16 변경44,633/9,074,964px(0.4918%). 이 중99.49%는 기존 경계 주변(5×5팽창 기준)에 있다. lite18h→lite16 변경20,299px(0.2237%),99.55%경계주변. 경계주변이라는 사실은 작은 구조의 연결성/클래스 변경이 없다는 뜻은 아니다.

lite20→lite16에서는 A122의224px, A51의161px, A87의194px짜리 독립Primary Si예측영역이 해당위치에서 사라지고주로Eutectic Si로바뀐다. lite18h에서이미생긴변화이며B4ws2fold축약탓으로분류하면안된다. 비교패널small_primary_changes.png에표시했다. 형태만으로정답확정은불가능하나추가검토대상이다.

lite18h→lite16에서완전히사라진10px이상기존클래스연결영역(4연결)은7개,최대22px이며Al3Ni/Eutectic Si에해당한다. Primary Si는이조건에해당하는삭제없음. 경계이동과작은연결성변화는여전히가능하다. 현재2foldB4ws축약에뚜렷한대규모시각악화증거는못찾았으나test정확도동등성증명은아니다.
