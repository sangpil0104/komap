# Al·Eutectic 전용 IoU 보정 학습 실험

같은 31×31 문맥 보정기와 4fold×400 업데이트를 사용하되, 원본 Al·Eutectic 예측 픽셀만 두 클래스 사이에서 바꾸도록 제한했다. 손실은 0.2 pair BCE + 0.8 crop별 soft Eutectic IoU + 잔차 L2다. Primary Si·Al3Ni 예측 마스크 불변을 70장마다 검사했다.

기준 79.9858620081%, 후보 meta-OOF 79.9372465929%, 차이 **-0.0486154152%p**로 손해다. 클래스별 변화(route 순서)는 [0.0, 0.0, -0.028632355777738722, -0.1658293048352078] %p다. 70장 저장 IoU를 독립 재합산해 점수와 rare class 불변을 확인했다. 후보는 기각하고 valid 후속은 실행하지 않는다.

train70만 사용하고 valid/test는 읽지 않았다. 기존 base OOF를 재사용한 meta-OOF이므로 엄격한 중첩 base 학습 검증이 아니다. 부모 특징 SHA는 불변이며 원본 base를 유지한다.
