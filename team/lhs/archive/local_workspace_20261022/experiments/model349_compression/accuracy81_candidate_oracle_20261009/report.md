# R + E 1단계 마스크 결합 후보

## 대표 후보와 점수

대표 후보는 **1단계 R + E**다. R은 Model349_exh14, E는 P100 Model329 B4 4-fold 및 Model392 HRNet 2-seed × 4-fold 앙상블이다. E가 Al3Ni 또는 Al로 예측한 픽셀만 E를 따르고 나머지는 R을 유지한다. 보정기 F는 필요 없다.

| 구성 | valid20 mIoU | 시편 제외 선택 |
|---|---:|---:|
| exh14 | 80.2312% | 기준 |
| 1단계 R + E | **80.4746% (+0.2434%p)** | **80.4088% (+0.1776%p)** |
| 2단계 + F | 80.5007% (+0.2695%p) | 80.3160% (1단계 대비 −0.1586%p) |

2단계 F는 전체 valid 탐색에서는 +0.0261%p지만 조건부 시편 제외 선택에서 1단계보다 낮아 대표 후보로 채택하지 않는다. 릴리스 대비 +0.0848%p라는 사실만으로 추가 단계의 유효성을 주장하지 않는다. 확신도 제한 80.5123%도 같은 반복 valid 탐색의 별도 결과이며 대표 후보로 승격하지 않는다.

## 시편 제외 선택의 정확한 범위

`fusion_screen.py`는 같은 시편 접두사(A63 등)의 모든 영상을 선택 자료에서 제외한다. 남은 영상에서 **69개 실행 × 각 30개 규칙 전체**를 다시 고르고, 제외한 영상의 IoU를 기록한다. 실행 E를 전체 valid에서 먼저 고정하고 규칙 30개만 재선택한 값이 아니다. 공식 지표와 같이 제외 영상들의 image mIoU를 20장 평균한다. 독립 재계산 및 선택 내역 대조는 `fusion_screen_cv_audit_result.json`에 기록한다.

다만 69개 후보 모델 자체가 이전에 반복 사용한 valid를 보고 개발됐고 릴리스 R도 valid에서 선택됐으므로, 이 재선택이 과거 개발 선택 편향을 모두 없애지는 않는다. 독립 일반화 검증값으로 보고하지 않는다. 2단계의 80.3160%는 첫 단계를 전체 valid에서 고정한 조건부 평가이므로 1단계 CV와 선택 범위도 다르다.

## 영상별 손실과 기존 기준

최악 영상 A71_step2_sample1은 **−0.2300%p**이며 기존 최악 영상 손실 기준(−0.10%p)을 통과하지 못해 `quality_pass: false`다. Primary Si가 없는 영상이라는 특징으로 미통과 사실을 면제하지 않는다. 평균 개선은 있지만 기존 base는 유지한다.

## 재현과 제출 준비 상태

저장 부모 출력 기반의 1단계 PNG 20장 / GT 80개 IoU 독립 채점은 80.4746206171%와 일치했다. P100 가중치의 R에도 같은 규칙으로 +0.2393 / +0.2797%p가 관측됐다. 모두 같은 valid20 검사이며 GPU 단독 효과나 독립 일반화의 증거는 아니다.

1단계의 원본 영상부터 전체 부모를 다시 계산하는 valid20 재추론과 test10 마스크 생성·exh14 비교는 새 전용 실험 `accuracy81_stage1_fresh_20261009`에서 진행한다. test에는 GT가 없어 test mIoU는 계산하지 않는다. 완료와 독립 검증 전에는 제출 준비 완료로 보고하지 않는다.

train70만 감독학습에 사용했고 valid/test 정답을 학습에 넣지 않았다. 원본 가중치·릴리스·base는 보존한다. 81% 목표는 아직 미달이다. 80.5% ZIP은 2단계 탐색 결과의 보존본이며 대표 제출 후보로 권장하지 않는다.
