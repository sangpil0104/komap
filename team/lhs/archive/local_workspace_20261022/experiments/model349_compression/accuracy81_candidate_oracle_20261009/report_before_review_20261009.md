기존 valid20 전체 원본영상 실행 79개에서 입력 이미지 SHA와 저장 metrics를 PNG/GT로 대조했다. 동일 마스크를 합치면 독립 후보 69개다. 공식 지표는 각 이미지의 4개 클래스 IoU 평균(빈 union=0)을 20장 평균한 값이다. 릴리스 `Model349_exh14` 80.2312313%를 독립 재현했다.
