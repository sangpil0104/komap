# base12 + 80.23098% 후보 고정 1:1 평균

사용자가 두 모델의 평균을 요청했다. 저장 확률 재생에서 각 구성의 최종 4클래스 융합 확률(mixed)을 구하고, 0.5*base12 + 0.5*best14를 공통 prior/공간 필터/cleanup 직전에 적용한다. 이 위치와 0.5는 결과를 보기 전에 고정하며 비율 탐색은 하지 않는다. 서로 다른 앙상블이므로 checkpoint tensor를 평균하는 것이 아니다.

각 모델 단독의 출력/IoU를 기존 replay와 먼저 대조한다. valid20 image mIoU는 이미지마다 4 IoU 평균 후 20개 이미지 평균, empty union=0이다. base12 대비 평균 손실≤0.01%p, 최악 이미지 손실≤0.10%p를 확인한다. 원본 추론/속도/독립 일반화 평가가 아니며 기존 base를 변경하지 않는다. test10은 정답이 없고 이번 CPU 실험에는 test probability cache를 사용하지 않는다.

필요 고유 가중치는 16개: 322 fold3·4, 326 fold1·2·3, 329 전체4fold, HR336/347, 269, high restart51/model109/seed456/pairwise. 동일 checkpoint 예측을 재사용하면 12+14=26개를 각각 실행할 필요는 없지만, base12보다 가중치 수가 증가한다. 실제 시간·파일 크기는 별도 원본 실행 전에는 주장하지 않는다.
