# Model349 lite 저장 정밀도·TENT 단계 축소 사전 기준

목적: 15가중치 `349_lite`보다 **저장 용량과 실제 추론 시간**을 모두 줄이되,
공식 `image_mean_mIoU`(4상, empty union=0)를 사실상 유지한다.

비교 대상: 같은 P100에서 원본 영상 valid 20장을 처리한
`lite_rep_free_bundle_v2_valid20`(80.0643596%, 366.56초 단회).
14가중치 원본 정밀도는 `lite14_ema_pruned_valid20`(80.0650399%, 417.09초 단회).

순서: (1) 14가중치의 FP32 텐서를 디스크에서 FP16으로 저장하고, 기존
FP32 모델에 로드한다. (2) 이 FP16판의 TENT 5-step을 독립 채점한다.
(3) 같은 FP16판을 TENT 3-step으로 독립 채점한다. FP16과 단계 축소는
각각의 효과를 분리해 비교한다. 두 번 모두 동일 valid 20장, 동일 GPU 6,
동일 추론 코드/후처리/평가식을 사용한다.

탐색 채택 기준:

- 체크포인트 총 바이트가 15가중치판보다 적을 것.
- 공식 평균 점수 하락이 15가중치판 대비 **0.01%p 이하**, 이미지별 최대
  하락이 **0.10%p 이하**일 것. 점수 동률 정도의 변동도 이미지별로 표시한다.
- 실제 경과 시간이 줄어야 한다. 단회 GPU 시간은 변동이 크므로 10% 미만
  차이는 속도 향상 확정으로 선언하지 않고 재측정 대상으로 둔다.
- 이 기준을 통과해도 valid 반복 사용으로 인한 선택 편향이 있으므로
  test 정답 점수 유지의 증거로 해석하지 않는다. test는 정답 없이 기존
  마스크와의 일치율만 확인할 수 있다.

FP16판의 config에 복사된 `validation_image_miou`는 원본 정밀도판의
과거 수치이며 새 점수가 아니다. 새 점수는 각 실행의 `metrics.json`을
권위 있는 근거로 삼는다.
