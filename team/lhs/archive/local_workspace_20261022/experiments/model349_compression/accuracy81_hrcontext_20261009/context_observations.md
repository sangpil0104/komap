# 문맥 확대 입력 감사

현재 학습 recipe의 70개 이미지 경로와 SHA를 확인했다. valid는 이미 기록된 input manifest의 이름과 SHA만 읽었으며 정답을 열지 않았다. 정확히 같은 이미지 SHA는 train과 valid 사이에 없었다.

17개 train 이미지는 675×480이다. native crop512를 만들 때 기존 dataset의 reflection padding으로 높이32픽셀을 추가한다. 다른53장은 native crop512보다 크다. 이 반사 영역도 손실 계산에 들어가므로 문맥 확대를 순수한 실측 영역 확대라고 부르지 않는다. 입력 전체 크기는 최소675×480, 최대1440×1024다. 세부 이미지 목록은 context_data_audit.json에 있다.

시편 ID가 train/valid 양쪽에 있는 것은 A125,A153,A181,A191,A40,A55,A7이다. 공식20장 점수는 그대로 보고하되 학습 시편과 겹치는 valid 이미지와 겹치지 않는 valid 이미지의 점수·변화를 기술 통계로 추가한다. 이 분리는 추가 학습이나 후보 선택에 사용하지 않는다. 같은 valid에서 모델 구성과 개발 후보를 반복 선택했으므로 시편이 겹치지 않는 부분도 전체 개발 과정으로부터 독립된 최종 평가셋이라고 주장하지 않는다.
