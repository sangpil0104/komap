2-1 전처리 방법
‘가로 폭 정규화(E)’ 문장을 다음으로 교체:
“E의 B4ws는 이미지 가로 폭을 4000픽셀로 맞추고, HR392 세 모델은 각 학습 fold의 최빈 가로 폭(1230 또는 1278픽셀)을 기준으로 정규화한 뒤 2배 확대한다. N3는 폭 정규화를 적용하지 않고 원본 이미지를 2배 확대한다.”
N3 입력 설명 추가:
“N3는 전체 이미지의 기존 밝기, 상대 밝기(Z-score), 밝기 순위(CDF)를 각각 한 채널로 표현한 RGB 영상을 입력으로 사용한다. Z-score는 ±4 범위를 0~1로 변환하고, CDF와 함께 8비트로 저장한다.”
주의: B4의 float32 입력 변환과 N3의 RGB8 인코딩을 같은 정규화 과정으로 설명하지 않음.

2-2 전처리 절차
4-fold 설명 뒤에 추가:
“최종 구성은 학습한 fold 중 일부를 사용한다. E의 N3는 fold 모델이 아니라 학습용 70장 전체로 추가학습한 모델이다.”
TTA 문장:
“B4는8방향으로 예측한 확률을 평균하고, E의 HR392 세 모델은4방향 뒤집기 평균을 사용한다. R의 HR347과 E의 N3는 단일 방향으로 예측한다.”
현재 R infer_lite.py는 HR347을 tta=False로 호출하고, predict_probs_tta는 tta=False일 때단일방향만사용하므로 설정파일의tta_mode=flip4만으로4방향이라고설명하면안됨.

3-1 모델 구성 선택 근거
‘R 구성원 선택’의 8,093개/11개/80.23%는 이전 구성의 선택 과정이므로 역사적 결과임을 명시하거나 현재 구성 설명과 분리.
현재 구성 설명용 문장:
“R은 ResNet34 계열 2개, B4 계열 6개, HRNet 1개의 총9개 가중치를 사용한다. E는 B4ws 두fold와 HR392 세fold, 전체 학습용 이미지로 추가학습한 N3 한 모델로 구성된다. N3는 기존 E의 HR392 seed1 fold2 한 자리를 교체한다.”
‘E’ 문장:
“현재 E의 단독 점수는79.6302%이며 R의79.7993%보다 낮다. 그러나 E가 Al3Ni 또는 Al로 예측한 픽셀을 사용하면 R+E 점수가80.5910%로 올라간다. 단독 평균 점수와 다른 모델의 오류를 보완하는 효과를 구분해 구성하였다.”
‘F’ 문장:
“기존8epoch 가중치를 유지한 F는 새 E의 확률을 입력받아 Al 판단을 보정한다. 현재 구성에서80.5910%→80.6285%로0.0375%p 상승했다.”
단독 비교표의 ResNet34/B4/HRNet 예전 값은 현재 사용 fold/모델의 점수가 아니므로 ‘구성 선택 당시 비교 결과’로 표시. 하단 R/E/최종 행은 current_stage_scores.csv 값으로 교체.
‘앙상블 효과’의 최종80.55%는 현재80.63%로 갱신하되,78.38%/78.83%는 이전 단독 비교값임을 명시.
‘시편을 빼고 다시 선택하는 교차 검증’은 선택 안정성 점검이며 독립적인 일반화 검증으로 표현하지 않음.

3-2 모델링 방법
① 모델 학습 문장:
“B4와 HR392는4-fold로 학습한 모델 중 일부를 사용하고, N3는 학습용70장 전체로 추가학습한다. 최종 사용 가중치는 R9개, E6개, F1개이다.”
ResNet34 항목:
“ResNet34 계열2개는 고해상도 경로의 restart61과 원본 해상도 경로의 model269이다. 고해상도 경로는 모든 이미지에서 restart61로 고정한다.”
→ ‘고해상도4개’, 기본모델/좁은159~161밝기구간별교체 설명 삭제. model269 원본해상도 경로는 유지.
B4 항목:
“R의 B4는322 fold3 한 개,326 fold1·2 두 개,329 fold1·3·4 세 개로 총6개이다.” 기존 fold 목록은 유지.
HRNet 항목:
“R에는 HR336에서 드문 상 가중치로12epoch 추가학습한 HR347 한 모델을 사용한다. 이 모델의 예측을 기존 HR336의 역할과 HR347의 역할에 공유한다.”
→ ‘기본1개+드문상1개’, ‘두 번째만Al에25%반영’으로 설명하면 현재 구조와 불일치.
E 항목:
“E는 B4ws fold1·3 두 개, HR392 seed1 fold4·seed2 fold1·seed2 fold4 세 개, N3 seed414 한 개로 총6개이다. N3는 HR336을 부모로 삼아 전체 학습용70장의 RGB8 ZCDF 입력으로25epoch 추가학습한 모델이다.”
N3 학습조건(필요한 경우 표에 추가): patch512/inputscale2/samples12/batch4×accum2/LR2e-4/encoderLR배율0.5/wd1e-4/CE+Dice+boundary/25epoch/last only/valevery0.
⑤ E 덮어쓰기 문장:
“E는 B4ws fold1·3의 평균50%, N3와 HR392 seed1 fold4의 평균25%, HR392 seed2 fold1·4의 평균25%로 결합한다. E가 Al3Ni 또는 Al로 판단한 픽셀을 E의 라벨로 교체하고 다른 픽셀은 R의 라벨을 유지한다.”
→ ‘두 HRNet 시드의 평균 각25%’는 N3가 들어간 현재 그룹을 정확히 설명하지 않으므로 위 문장으로 교체.
⑥ F 학습 설명:
“F는 원래 E 구성의 train70 OOF 예측으로8epoch 학습한 기존 가중치를 유지한다. 이번 구성에서는 새 E의 log 확률과 원본 밝기를 입력으로 사용하고, F가Al로 판단한 픽셀만 최종 결과에 반영한다.”
→ 새N3 구성 자체의 OOF로 F를 다시 학습했다고 설명하지 않음. N3 train70 모델에는 해당70장을 제외한 OOF 예측이 없음.

모델 학습량 표
R ResNet34:3개→2개(restart61/model269).
R B4:6개 유지.
R HRNet 기본1개 행 삭제, HR3471개 행만 유지(부모70epoch+추가12epoch).
E B4:4개→2개(fold1·3), BN고정2000step 추가학습 설명 유지.
E HRNet widthnorm:4개→3개(seed1fold4/seed2fold1/seed2fold4),70epoch.
E N3:1개 행 추가(전체train70/RGB8 ZCDF/폭정규화없음/HR336부모에서25epoch추가학습).
F:1개/기존8epoch 유지.

3-3 성능 갱신
검증 점수:80.546432%→80.628461% (소수 둘째자리80.63%). 원문 표80.55%와 본문80.546432%도 서로 달랐으므로 현재 독립채점값으로 통일.
R/E/최종 및상별IoU는 current_stage_scores.csv, 재현율·정밀도는 current_class_metrics.csv 사용.
A71:54.0991%, PrimarySi가없는상0 포함. 나머지세상 평균72.1321%.
낮은상IoU: A153 EutecticSi30.7541%, A74 EutecticSi39.8180%, A11_step1 Al3Ni56.1922%, A67 Al3Ni59.0271%.
혼동픽셀: GTAl3Ni→Al184,575(약18.5만), GTAl3Ni→EutecticSi148,704(약14.9만), GTEutecticSi→Al3Ni139,882(약14.0만).
오류위치: 원문85.6%의 정확한경계정의 미확인. 이번 독립계산은 정답의상하좌우상변화 양쪽픽셀을경계로 잡고8이웃반경1픽셀팽창한영역을사용했으며,오류의88.7366%가그영역에포함. 기존통계와같은정의로간주해숫자만교체하지말고정의명시 또는원문통계스크립트로재계산.
시험용그림4는새seed414의실제최종예측을사용. test10 GT없음/정확도수치주장안함.

전체 원칙
- 모델구성 수·그림·표·성능을같은lite16-N3 버전으로통일.
- 모든valid20 값은반복개발에사용한검증셋점수. 새로운독립일반화점수로표현하지않음.
- 원래lite20/lite16 결과, 팀원seed탐색, 현재추가실험을현재채택모델의fresh결과와혼합하지않음.
