# HRNet 질감 입력 대조 실험

## 목적과 범위

같은 HRNet seed1/fold1 체크포인트에서 원본 RGB 입력과 [회색조, 저주파, 언샤프] 입력을 같은 예산으로 추가 학습한다. train70의 fold1 분할(학습 52장, 보류 18장)만 사용한다. 공식 valid20, test10, Claude의 OOF90 작업과는 별도다.

각 입력을 4 epoch 학습한 마지막 체크포인트로 flip4 추론한다. 후보의 보류 점수가 대조군보다 0.1%p 이상 높고 Al3Ni·Primary Si 각각의 하락이 0.1%p 이하일 때만 다른 fold 검증을 진행한다. 단일 fold 결과로 전체 성능 또는 81% 달성을 주장하지 않는다.

## 실행과 검증

서버의 run_sequence.py가 원본 학습 → 질감 학습 → 원본 평가 → 질감 평가를 순차 실행한다. started.json이 있으면 중복 실행을 거부한다. GPU 3의 잠금 및 NVML PID를 확인하며 다른 프로세스가 나타나면 우리 자식만 중단한다. 원본 체크포인트와 데이터 SHA를 종료 시 재확인한다.

완료 후 verify_results.py로 저장된 FP16 확률을 정확한 RGB GT 팔레트에 독립 채점한다. FP32 평가기의 점수와 FP16 독립 점수를 구분한다. 두 점수는 양자화 때문에 소폭 다를 수 있다.

## 재현성 한계

시드와 per-item RNG, 결정적 cuDNN 설정을 고정했다. 전체 연산의 bitwise 결정성 및 다른 GPU에서의 재학습 재현은 아직 검증하지 않았다. 양 군 모두 기존 가중치에서 추가 학습하므로 처음부터의 재학습 검증도 아니다.
