# Eutectic Si 31×31 문맥 보정 학습 실험

7,713개 파라미터의 팽창 합성곱 보정기로 기존 E의 Eutectic Si 점수만 ±1 이내에서 수정했다. train70에서 grouped fold 하나씩을 제외하고 나머지 영상으로 400회씩 학습했다. 고정 마지막 체크포인트를 평가했으며 valid/test는 읽지 않았다.

기준 **79.9858620081%**, 후보 meta-OOF **79.9637103823%**, 차이 **-0.0221516258%p**로 손해다. 70장 클래스 IoU를 로컬에서 독립 재합산해 확인했다. 후보는 기각하고 valid 후속은 실행하지 않는다.

이는 기존 base OOF를 재사용한 탐색용 meta-OOF이며, base까지 중첩 재학습한 독립 일반화 검증이 아니다. 기준 모델과 학습 특징은 불변이다.

초기 결정적 CUDA CE 오류는 수식이 같은 log-softmax CE로 수정했다. NVIDIA PID와 컨테이너 PID가 달라 생긴 감시 종료는 단일 CUDA 생성 전후 PID 등록으로 해결했다. 4개 fold 학습 후 결과 JSON의 NumPy bool 저장 오류는 체크포인트 평가만 다시 실행해 복구했다. 복구 전후 네 체크포인트 SHA가 같아 재학습하지 않았음을 확인했다. 실패 시도와 로그는 서버의 attempt 폴더에 보존했다.
