# 고해상도 선택 모델 축소: 사전 기준

이 문서는 15가중치 패키지의 `--force-high-source restart51` valid 결과를 보기 전에 작성했다.

## 비교 대상과 지표

- 기준: 독립 15가중치 패키지의 원본 영상 valid20 재추론 `80.0643596%` (image-wise 4-class mIoU, empty=0).
- 후보: 이미지 밝기별로 선택되던 고해상도 모델 5개 중 `restart51` 하나만 유지. 나머지 4개 체크포인트를 제거할 수 있으므로 15→11개.
- 기존 B4 4-fold 두 세트, HRNet336, native269, TENT 5단계, 후처리·고정 route는 변경하지 않는다.
- 새 후보의 valid20 평균뿐 아니라 `restart51` 이외의 모델이 원래 선택되던 이미지들의 **개별 점수 변동**을 본다. 평균이 같아도 특정 이미지에서 크게 악화하면 채택하지 않는다.
- 이후 test10의 기존 경량판 출력과 마스크 픽셀 일치율을 본다. 정답이 없어 test 점수라는 주장은 하지 않는다.

## 판정

11가중치 후보는 valid 손실이 15가중치 대비 `0.02%p` 이하이고, 개별 valid 영상의 최대 악화가 `0.5%p` 이하이며, test 마스크 일치율이 `99.95%` 이상일 때만 **추가 검증 후보**로 채택한다. 이 기준을 넘으면 15가중치판을 유지하고, 이미지별 독립성 덕분에 각 밝기 선택 모델을 개별적으로 빼는 조합을 진단한다. 그 조합도 반복 사용한 valid에서 골랐다는 한계를 명시한다.

이 기준은 test mIoU 유지나 독립 일반화를 입증하지 않는다. 최종 교체를 정당화하려면 held-out specimen 또는 신규 검증 자료가 필요하다.
