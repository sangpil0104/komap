# 12개 base 고해상도 4방향 예측: 고정 후속 실험

입력 캐시 반복 실험 종료 후 GPU7 잠금과 유휴 상태를 확인하고 단일 작업으로 실행한다. 기존 GPU/CPU 작업과 원본 base를 변경하지 않는다.

변경은 고해상도 경로의 D4 8방향 예측을 identity·좌우반전·180도회전·상하반전의 대칭적인 4방향으로 줄이는 한 가지다. 기존 legacy 모드는 방향 구성이 달라 사용하지 않는다. TENT5, 원본·밝기 보정 두 입력, 모든 가중치·밝기별 경로·결합 계수·후처리·HRNet은 유지한다. B4 입력 캐시 변경도 포함하지 않는다.

원본 valid20 재추론 후 공식 image mIoU 및 이미지별·클래스별 변화와 실제 시간을 기록한다. base12 및 기존 lite15 각각에 대해 평균 손실 ≤0.01%p, 최악 이미지 손실 ≤0.10%p를 모두 통과해야 후속 측정한다. 이중 조건을 실행 전에 명시한다.

통과하면 새로운 control12/후보를 A-B, B-A, A-B 순서로 각각 3회 재추론하고, 전체 시간 중앙값 10% 이상 감소·모든 반복의 이중 품질 조건 통과·GPU7 타 프로세스 간섭 없음이어야 탐색 조건에서 시간 개선으로 판정한다. 공유 CPU 부하와 회차별 변화도 보존한다. 과거 단회 기록과 직접 비교하지 않는다.

품질 통과 후보만 test10 원본 재추론 후 기존 base 마스크 일치율을 기록한다. test 정답·IoU는 없다. 기각 시 4방향 종류·TENT·계수를 추가 조정하지 않는다. 신규 데이터가 없으므로 독립 일반화 검증으로 주장하지 않는다. 가중치 수·바이트는 12개/683,320,900바이트 그대로다.
